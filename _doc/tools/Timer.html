Timer

  • Parametrar
  • Beskrivning
  • Start-/stoppknapp
  • Display
  • Tidur

Timer är ett verktyg för att kontrollera korta tidsgränser som används i flera kriterier i WCAG; till exempel att vissa kontroller ska vara uppfyllda om något pågår i ett angivet antal sekunder.

Parametrar i granskningskonfigurationen

{
    "tool":   "module",
    "module": "Timer",
    "params": {
        duration: varaktighet
   }
}
duration
Mätperiodens varaktighet i millisekunder.

Beskrivning

Verktyget består av tre klasser: en start- och stoppknapp, en resultatdisplay och ett tidur.

TimerButton

Klassen TimerButton representerar den start- och stoppknapp som användaren interagerar med.

Konstruktor

Konstruktorn skapar knappelementet, utan att infoga det i DOM-trädet.

Syntax

new TimerButton(doc, timer, display)

Parametrar

doc
DOM-dokument.
timer
Tidur; en instans av klassen Timer.
display
Resultatdisplay; en instans av klassen TimerDisplay.

appendTo()

Infogar start- och stoppknappen i DOM-trädet.

Syntax

appendTo(parent)

Parametrar

parent
Behållarelement att infoga knappen i.

Returvärde

Inget (undefined).

TimerDisplay

Klassen TimerDisplay representerar resultatdisplayen som visar den förflutna tiden (i millisekunder) när tiduret stoppas. Displayen har en visuell indikering av om tiduret stoppats av användaren innan tidsgränsen löpt ut eller om det stoppats automatiskt efter den angivna tidsgränsen.

Displayen visar även en indikator medan tiduret är igång.

Konstruktor

Konstruktorn skapar ett <output>-element som ska uppdateras med resultatet när det är tillgängligt.

Syntax

new TimerDisplay(doc)

Parametrar

doc
DOM-dokument.

appendTo()

Infogar displayen i DOM-trädet.

Syntax

appendTo(parent)

Parametrar

parent
Behållarelement att infoga displayen i.

Returvärde

Inget (undefined).

clear()

Rensar displayen och visar en indikator på att tiduret har startats. Indikatorn är en horison­tell ellips (”…”)

Syntax

clear()

Returvärde

Inget (undefined).

update()

Uppdaterar displayen med den förflutna tiden när tiduret stoppats. Tiden visas i milli­sekunder och elementet åsätts en klass som ger en färgindikering på om tiduret stoppats på grund av att tidsgränsen löpt ut (rött) eller om användaren stoppat det för att den aktivitet man vill mäta har upphört (grönt).

Syntax

update(timer)

Parametrar

timer
Tiduret som stoppats.

Returvärde

Inget (undefined).

Timer

Klassen Timer är ett enkelt tidur som startas manuellt och stoppas antingen manuellt eller automatiskt efter en angiven varaktighet (tidsgräns).

Konstruktor

Syntax

new Timer(duration)

Parametrar

duration
Varaktighet (tidsgräns) i millisekunder, efter vilken tiduret stoppas automatiskt om inte användaren dessförinnan stoppat det manuellt.

Fält

elapsed
Den förflutna tiden, i millisekunder, från att tiduret startades tills det stoppades (manuellt eller automatiskt).
expired
En flagga som indikerar om tiduret stoppades automatiskt efter den angivna tidsgränsen (true) eller om det stoppades manuellt av användaren (false).

start()

Startar tiduret.

Syntax

await start()

Returvärde

Ett löfte som infrias när tiduret stoppats, manuellt eller automatiskt.

stop()

Stoppar tiduret manuellt.

Syntax

stop()

Returvärde

true om tiduret var igång och stoppades, annars false.
