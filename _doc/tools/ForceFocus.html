ForceFocus

ForceFocus är ett bookmarklet som kan underlätta kontroller som kräver tangentbords­navigering på webbplatser som har dålig fokusmarkering (eller döljer den helt).

Installation

Användaren installerar bokmärket genom att kopiera skriptkoden (”länkadressen”) och klistra in den i ett nytt bokmärke. I många webbläsare kan man också dra verktygslänken till bokmärkesraden för att installera den.

En alltför strikt CSP (content security policy) på en server kan förhindra att ett bookmarklet går att exekevera.

Funktion

Verktyget injicerar CSS-kod på sidan för att definiera en tydlig fokusmarkering. Verktyget injicerar koden även på externa dokument som bäddats in med <iframe>.

Verktyget tar bort den injicerade CSS-koden om det exekveras en andra gång på samma sida, vilket innebär att man inte behöver ladda om sidan för att återställa den.
