case.module.js

Modulinitiering för visning och redigering av ärenden.

initModule()

Anropas av fördelaren (Dispatcher) för att instantiera vy och controller.

Funktionen använder applikationskontexten för att se vilka parametrar begäran innehåller och importerar moduler samt instantierar vy och controller baserat på det.

Om begäran saknar parametern ”case” ska ett nytt ärende skapas. Om ”case” finns och även parametern ”edit” ska ett befintligt ärende redigeras. I båda fallen instantierar funktionen CaseEditView och CaseEditController.

Om begäran innehåller ”case” men inte ”edit” ska det angivna ärendet visas och funktionen instantierar CaseDisplayView och CaseDisplayController.

Syntax

initModule(model, context)

Parametrar

model
Modellobjektet.
context
Applikationskontext.

Returvärde

Ett objekt med två fält: controller och view.
