ContentMenu

Klassen ContentMenu utökar Menu och representerar en innehållsmeny med ankarlänkar till asvnitt på sidan. Den indikerar visuellt det ”aktuella” elementet baserat på skroll­positionen.

Källkod
js/menu/ContentMenu.js
Enhetstester
_tests/menu/ContentMenu.test.js

Konstruktor

Konstruktorn registrerar en händelselyssnare för skrollning, för att uppdatera vilket element i menyn som är ”aktuellt”.

Syntax

new ContentMenu(element)
new ContentMenu(element, label)

Parametrar

element
Det <ul>-element som representerar menyn i DOM-trädet.
label
Etikett som förmedlas till hjälpmedel (”Innehåll”, om inget annat anges).

Fält

current
Aktivt (fokuserat) menyelement. Vid skrivning hanterar klassen också tabbindex för underliggande element. (Endast det aktiva elementet ingår i navigeringssekvensen.)

add()

Lägger till ett menyelement i menyn.

Metoden sparar offset för menyelementets målelement. Dessa offset används sedan för att räkna ut vilket menyelement som är ”aktivt” vid en viss skrollposition.

Syntax

add(item)

Parametrar

item
Menyelement att lägga till.

Returvärde

Inget (undefined).

down()

Returnerar menyelement nedanför det angivna referenselementet.

Uppdaterar menyns ”aktiva” elemeent vid navigering.

Syntax

down(ref)

Parametrar

ref
Referenselement.

Returvärde

Nästa MenuItem-element efter referenselementet.

Undantag

TypeError
Referenselementet ingår inte i menyn.

handleLeft()

Hantera navigering med vänsterpil.

En innehållsmeny är vertikal och har inga undermenyer, så metoden, som ersätter basklassmetoden, gör ingenting.

Syntax

handleLeft(ref)

Parametrar

ref
Referenselement.

Returvärde

Referenselementet.

up()

Returnerar menyelement ovanför det angivna referenselementet.

Uppdaterar menyns ”aktiva” elemeent vid navigering.

Syntax

up(ref)

Parametrar

ref
Referenselement.

Returvärde

Föregående MenuItem-element från referenselementet.

Undantag

TypeError
Referenselementet ingår inte i menyn.

Beskrivning

En innehållsmeny är en vanlig meny utan undermenyer, som består av länkar till avsnitt inom sidan. Det ”aktiva” elementet indikeras visuellt och denna indikering uppdateras så snart skrolllpositionen i dokumentet förändras.

Algoritmen för att beräkna ”aktuellt” element är rudimentär och inte alls optimal. Den söker det sista elementet i menyn vars målelement, eller målelementets efterföljande innehåll, är synligt i fönstret med den aktuella skrollpositionen.
