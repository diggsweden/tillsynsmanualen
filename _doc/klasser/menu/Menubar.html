Klassen Menubar utökar Menu och representerar en horisontell menyrad med nedfällbara undermenyer.

Menyraden implementerar designmönstret Menu bar, vilket innebär att hela menyraden utgör ett enda tabbstopp i navigeringssekvensen. Navigering inom menyraden sker med piltangenter.

Källkod
js/menu/Menubar.js
Enhetstester
_tests/menu/Menubar.test.js

Konstruktor

Konstruktorn sätter rollen menubar på det underliggande elementet och sätter menyns orientering till horisontell.

Syntax

new Menubar(element)

Parametrar

element
Det <ul>-element som representerar menyraden i DOM-trädet.

Fält

current
Aktivt (fokuserat) menyelement. Vid skrivning hanterar klassen också tabbindex för underliggande element. (Endast det aktiva elementet ingår i navigeringssekvensen.)
id
En unik identifierare för menyraden.

down()

Öppnar referenselementets undermeny, om det har någon, och sätter fokus till första elementet.

Syntax

down(ref)

Parametrar

ref
Referenselement.

Returvärde

Första elementet i undermenyn, eller this om referenselementet inte har någon undermeny.

handleLeft()

Hantera navigering med vänsterpil. (Referenselementet är ett element i en undermeny.)

  1. Stäng referenselementets undermeny.
  2. Sätt föregående element i menyraden som aktivt element.
  3. Om det nya aktiva elementet har en undermeny, öppna den, men sätt inte fokus till något underelement.

Syntax

handleLeft(ref)

Parametrar

ref
Referenselement.

Returvärde

Elementet före referenselementet i menyraden. Om referenselementet är det första elementet i menyraden börjar metoden om från sista elementet (wrap around).

Undantag

TypeError
Referenselementet ingår inte i menyn.

left()

Hantera navigering åt vänster från det angivna referenselementet. (Referenselementet är ett element i menyraden.)

  1. Stäng referenselementets undermeny.
  2. Sätt föregående element i menyraden som aktivt element.

Syntax

left(ref)

Parametrar

ref
Referenselement.

Returvärde

Elementet före referenselementet i menyraden. Om referenselementet är det första elementet i menyraden börjar metoden om från sista elementet (wrap around).

Undantag

TypeError
Referenselementet ingår inte i menyn.

right()

Hantera navigering med högerpil från angivet referenselement. (Referenselementet är ett element i menyraden.)

  1. Stäng referenselementets undermeny.
  2. Sätt nästa element i menyraden som aktivt element.

Syntax

right(ref)

Parametrar

ref
Referenselement.

Returvärde

Elementet efter referenselementet i menyraden. Om referenselementet är det sista elementet i menyraden börjar metoden om från första elementet (wrap around).

Undantag

TypeError
Referenselementet ingår inte i menyn.

up()

Öppnar referenselementets undermeny, om det har någon, och sätter fokus till sista elementet.

Syntax

up(ref)

Parametrar

ref
Referenselement.

Returvärde

Sista elementet i undermenyn, eller this om referenselementet inte har någon undermeny.

Beskrivning

Skillnaden mellan en menyrad och en generell meny ligger främst i tangentbordsinterak­tionen.

Tangentbordsinteraktion för menyrad.
Tangent Funktion
Tabb Flytta fokus till elementet efter menyraden.
Skift+Tabb Flytta fokus till elementet före menyraden.
⭣ Om elementet som har fokus har en undermeny, öppna undermenyn och sätt fokus till dess första element.
⭡ Om elementet som har fokus har en undermeny, öppna undermenyn och sätt fokus till dess sista element.
⭢ Flytta fokus till nästa element och börja om från vänster efter sista elementet.
⭠ Flytta fokus till föregående element och börja om från höger efter första elementet.
