Klassen MenuItem representerar ett element i en meny. Elementet kan antingen vara en lövnod, det vill säga en länk, eller ha en utfällbar undermeny.

Källkod
js/menu/MenuItem.js
Enhetstester
_tests/menu/MenuItem.test.js

Konstruktor

Konstruktorn sätter role="menuitem" och sätter också tabindex="-1" på det under­liggande elementet för att ta bort det ur navigeringssekvensen, eftersom menyn själv hanterar sin interna navigering.

Syntax

new MenuItem(element)

Parametrar

element
Det element som representerar menyelementet i DOM-trädet.

Fält

current
Anger om elementet är ”aktuellt” element i sin meny. Det aktuella elementet har attributet aria-current.
focusable
Anger om elementet är ”aktivt”, det vill säga ingår i webbläsarens allmänna navigeringssekvens.
href
Det underliggande länkelementets href-attribut.
parentItem
Överordnat menyelement.
parentMenu
Överordnad meny.
submenu
Undermeny.

activate()

Aktiverar menyelementet.

Om elementet är en lövnod stänger metoden alla överordnade menyer och returnerar null för att signalera att händelsen inte ska anses som hanterad utan propageras så att den aktiverar länken.

Om elementet har en undermeny öppnar metoden den och sätter fokus till det första elementet.

Syntax

activate()

Returvärde

Det fokuserade elementet i undermenyn om en sådan finns, annars null.

close()

Stänger undermenyn (genom att sätta aria-expanded="false" på det underliggande elementet). Stänger också alla eventuella öppna underordnade menyer.

Syntax

close()

Undantag

TypeError
Elementet har ingen undermeny.

closeAll()

Stänger undermenyn (genom att sätta aria-expanded="false" på det underliggande elementet) och alla överordnade menyer.

Syntax

close()

Returvärde

Det översta menyelement ovanför det aktuella elementet.

focus()

Sätter tangentbordsfokus till det underliggande HTML-elementet.

Syntax

focus()

Returvärde

Returnerar this.

is()

Jämför angiven DOM-nod med menyelementets underliggande nod.

Syntax

is(node)

Parametrar

node
DOM-nod att jämföra med.

Returvärde

true om den angivna DOM-noden är menyelementets underliggande HTML-element, annars false.

open()

Öppnar menyelementets undermeny.

Syntax

open()

Returvärde

Returnerar undermenyn (en instans av Menu).

Undantag

TypeError
Menyelementet har ingen undermeny.

startsWith()

Kontrollerar om elementets textinnehåll börjar med angivet tecken (skiftlägesokänsligt).

Syntax

startsWith(char)

Parametrar

char
Tecken att jämföra med.

Returvärde

true om elementets textinnehåll börjar med det angivna tecknet, annars false.

toggle()

Växlar synlighet (genom att ändra värdet på aria-expanded) för elementets undermeny.

Syntax

toggle()

Returvärde

true om elementets har en undermeny, annars false.
