Länkstig (”brödsmulor”) för granskningssidor.

Länkstigen ingår i en vy, men populeras av en controller. Vilka länkar som sätts varierar beroende på vilken sida länkstigen ingår i, men det finns en hierarki: ärende → granskning → stickprov → krav.

Källkod
js/view/BreadcrumbTrail.js
Enhetstester
_tests/view/BreadcrumbTrail.test.js

Konstruktor

new BreadcrumbTrail()

Fält

current
Titel för aktuell sida.
links
Vektor med länkobjekt ({title, url}).

audit()

Specificerar aktuell granskning.

Syntax

audit(id, date)

Parametrar

id
Granskningsidentitet.
date
Granskningens startdatum.

Returvärde

Inget (undefined).

case()

Specificerar aktuellt ärende.

Syntax

case(id, caseNumber, org, service

Parametrar

id
Ärendeidentitet.
caseNumber
Ärendenummer (kan anges som en instans av CaseNumber eller som en sträng).
org
Aktörens namn.
service
Tjänstens namn.

Returvärde

Inget (undefined).

completed()

En asynkron funktion som slutförs när fältet current sätts.

Syntax

await completed()

Returvärde

Ett löfte som infrias när länkstigen är klar att visa, det vill säga när fältet current tilldelas titeln för den aktuella sidan, som är sista elementet i länkstigen.

deleteRoot()

Tar bort granskningsstartsidan ur länklistan. Används på själva granskningsstartsidan, eftersom den då är aktuell sida och anges som current.

Syntax

deleteRoot()

Returvärde

Inget (undefined).
