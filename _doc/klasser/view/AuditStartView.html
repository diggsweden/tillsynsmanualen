AuditStartView

  • Konstruktor
  • Fält
  • addAudit()
  • hideSource()

  • Se även

Vy för att skapa en ny granskning. Användaren anger vem som är granskare för ärendet och – för en mobil applikation – vilken version som granskas.

Användaren kan också välj att kopiera en existerande granskning i ärendet. Då kopieras stickprovsurvalet, vilket spar mycket tid vid en omgranskning.

AuditStartView ärver från ViewBase.

Källkod
js/view/AuditStartView.js
Enhetstester
_tests/view/AuditStartView.test.js

Konstruktor

Syntax

new AuditStartView(breadcrumbs, listeners, loader)

Parametrar

breadcrumbs
Länkstig (”brödsmulor”).
listeners
Händelselyssnarlista.
loader
Resursladdare.

Fält

officer
Granskare (e-postadress).
officers
Samtliga granskare i databasen; populerar en lista att välja ifrån.
service
Typ av digital service ("MobileApp" eller "Website").
source
Identifierare för granskning att kopiera.
version
Versionsnummer (för mobil applikation).

addAudit()

Lägger till en granskning i listan med existerande granskningar som användaren kan välja att kopiera.

Syntax

addAudit(id, label)

Parametrar

id
Granskningsidentitet.
label
Visningsnamn i listan.

Returvärde

Inget (undefined).

hideSource()

Döljer listan med existerande granskningar. Används när det inte finns någon tidigare granskning i ärendet.

Syntax

hideSource()

Returvärde

Inget (undefined).

showPreparation()

Visar en modal dialogruta med den katalogstruktur som granskaren bör skapa i filsystemet (under ärendekatalogen) för den nyskapade granskningen.

Syntax

await showPreparations(rootDir, yearDir, caseDir, auditDir)

Parametrar

rootDir
Sökväg till ärendekatalogen.
yearDir
Namn på årtalskatalogen.
caseDir
Namn på katalogen för det aktuella ärendet.
auditDir
Namn på granskningskatalogen.

Returvärde

Ett löfte som infrias när användaren stänger dialogrutan.
