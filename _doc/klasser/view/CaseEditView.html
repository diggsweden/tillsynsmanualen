CaseEditView

Vy för redigering av ärendeuppifter. Vyn består av ett formulär indelat i tre olika paneler med tabbfliksnavigering:

  • Ärendeinformation.
  • Information om den ansvariga aktören.
  • Information om den digitala service som ska granskas.

CaseEditView ärver från ViewBase.

Källkod
js/view/CaseEditView.js
Enhetstester
_tests/view/CaseEditView.test.js

Konstruktor

Syntax

new CaseEditView(breadcrumbs, listeners, loader, tabs)

Parametrar

breadcrumbs
Länkstig (”brödsmulor”).
listeners
Händelselyssnarlista.
loader
Resursladdare.
tabs
Tabbfliksnavigering

Fält

abbr
Förkortning av aktörens organisationsnamn.
access
Åtkomsttyp för webbplats (publik, extranät, intranät).
addr
Aktörens postadress.
appOS
Operativsystem för mobil applikation.
auth
Flagga som anger om den digitala servicen kräver inloggning eller annan autentisering.
caseNumber
Ärendenummer.
caseType
Ärendetyp (granskningsärende, anmälningsärende, övervakningsärende).
date
Datum för tillsynsbeslut i ett anmälningsärende.
email
Aktörens e-postadress.
org
Aktörens organisationsnamn.
regNo
Aktörens organisationsnummer.
schedule
Tillsynsplan i ett övervakningsärende.
schedules
Tillsynsplaner i rullgardinslista. (Endast skrivning.)
service
Den granskade digitala servicens namn.
serviceType
Typ av digital service (webbplats eller mobil applikation).
supervisor
Tillsynsansvarig för ärendet.
supervisors
Tillsynsansvariga i rullgardinslista. (Endast skrivning.)
tel
Aktörens telefonnummer.

activate()

Utökar ViewBase.activate() genom att lägga till händelselyssnare för försök till inskick av formulär med ogiltiga fält. Controllern behöver då se till att tabbpanelen som innehåller det (första) felande fältet är synlig, så att användaren kan se var felet är.

Syntax

activate()

Returvärde

Inget (undefined).

close()

Utökar ViewBase.close() genom att koppla ifrån tabbfliksnavigeringen när vyn stängs.

Syntax

close()

Returvärde

Inget (undefined).

open()

Utökar ViewBase.open() genom att koppla tabbfliksnavigeringen till knappar när vyn öppnas.

Syntax

await open()

Returvärde

Ett löfte som infrias när sidinnehållet laddats.
