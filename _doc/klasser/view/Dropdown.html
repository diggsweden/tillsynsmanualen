Dropdown

En rullgardinslista som består av en knapp och en listruta. Varje tryck på knappen växlar listrutans synlighet. Intressenter kan prenumerera på händelseinformation och aviseras om ändringar av markeringar i listrutan.

Dropdown använder Listbox för att hantera den nedfällbara listan (”rullgardinen”) och tillför bara lite kod för interaktionen med knappen.

Dropdown implementerades enligt ett designmönster med samma namn i WAI-ARIA Authoring Practices 1.1. Detta mönster är nu deprecated i ARIA Authoring Practices Guide, utan något fungerande alternativ med stöd för flerval.

Konstruktor

Syntax

new Dropdown(listbox, listeners, keyMap)

Parametrar

listbox
Listruta (rullgardin).
listeners
Händelselyssnarlista.
keyMap
Tangentmappare.

Fält

buttonText
Textinnehåll i knappen.

attach()

Kopplar rullgardinslistan till underliggande HTML-element i DOM-trädet och registrerar händelselyssnare.

Syntax

attach(button, list)

Parametrar

button
Knappen (<button>) som ska visa och dölja listan.
list
Lista (<ul>) som innehåller de valbara elementen; se Listbox.

Returvärde

Inget (undefined).

detach()

Tar bort registrerade händelselyssnare.

Syntax

detach()

Returvärde

Inget (undefined).

reset()

Återställer alla valdmarkeringar i listrutan.

Syntax

reset(selected)

Parametrar

selected
Vektor med identiteter för de element som ska vara förvalda.

Returvärde

Inget (undefined).

subscribe()

Registrerar en observatör på listrutan. När användaren markerar eller avmarkerar element i listrutan meddelas alla registrerade observatörer.

Se Listbox för information om observatörer och aviseringar.

Syntax

subscribe(notify)

Parametrar

notify
Observatör att meddela vid markeringshändelser i listrutan.

Returvärde

Inget (undefined).

Tangenter

Se Listbox för information om tangentmappningen i listrutan.

Tangentmappning för knappen i Dropdown.
Tangent Funktion
Enter Drar ned rullgardinen och fokuserar det första valda elementet.
Esc Drar upp rullgardinen.
⭣ Drar ned rullgardinen och fokuserar första elementet.
⭡ Drar ned rullgardinen och fokuserar sista elementet.
