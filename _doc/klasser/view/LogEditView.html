Vy för att skapa eller redigera en notering i ärendeloggen. Vyn används också för att se detaljerna i en notering.

LogEditView ärver från ViewBase.

Källkod
js/view/LogEditView.js
Enhetstester
_tests/view/LogEditView.test.js

Konstruktor

Syntax

new LogEditView(breadcrumbs, listeners, loader)

Parametrar

breadcrumbs
Länkstig (”brödsmulor”).
listeners
Händelselyssnarlista.
loader
Resursladdare.

Fält

data
Händelsespecifika data.
direction
Kommunikationsriktning (inkommet, skickat, internt).
readOnly
Flagga som anger om noteringen får redigeras.
summary
Noteringens sammanfattning.
text
Noteringens detaljtext.
timestamp
Noteringens tidsstämpel.
type
Noteringstyp.

disableData()

Aktivera eller avaktivera listan med händelsespecifika data.

Syntax

disableData(flag)

Parametrar

flag
Flagga som anger om listan ska avaktiveras.

Returvärde

Inget (undefined).

Returvärde

disableRemove()

Syntax

disableDirection()

disableTypes()

Avaktivera angivna element i listan med noteringstyper.

Syntax

disableTypes(types)

Parametrar

types
En vektor med noteringstyper att avaktivera.

Returvärde

Inget (undefined).

requireData()

Gör listan med händelsespecifika data obligatorisk eller frivillig.

Syntax

requireData(flag)

Parametrar

flag
Flagga som anger om listan ska vara obligatorisk.

Returvärde

Inget (undefined).

setData()

Populera listan med händelsespecifika data.

Syntax

setData(values)

Parametrar

values
En vektor med data att populera listan med. Varje element i vektorn är en vektor med två strängar: värde och synlig etikett.

Returvärde

Inget (undefined).

suggestSummary()

Föreslå en sammanfattningstext. Anropet ignoreras om det redan finns ett värde i fältet.

Syntax

suggestSummary(text)

Parametrar

text
Förslag på sammanfattning.

Returvärde

Inget (undefined).
