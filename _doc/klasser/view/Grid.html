Grid

  • Konstruktor
  • attach()
  • detach()
  • Tangenter
  • Se även

Ett rutnät: en komponent som presenterar innehåll i rader och kolumner. Hela rutnätet utgör ett enda tabbstopp i sidans navigeringssekvens. Navigering inom rutnätet sker med piltangenter.

Grid implementerar designmönstret Grid i ARIA Authoring Practices Guide.

Källkod
js/view/Grid.js
Enhetstester
_tests/view/Grid.test.js

Konstruktor

Syntax

new Grid(listeners, keyMap)

Parametrar

listeners
Händelselyssnarlista.
keyMap
Tangentmappare.

attach()

Kopplar rutnätet till underliggande HTML-element i DOM-trädet och registrerar händelse­lyssnare.

Registrerar också en mutationslyssnare för förändringar i DOM-trädet.

Syntax

attach(element)

Parametrar

element
HTML-element att koppla rutnätet till.

Returvärde

Inget (undefined).

detach()

Tar bort registrerade händelselyssnare och återställer elementet i navigeringsordningen.

Syntax

detach()

Returvärde

Inget (undefined).
