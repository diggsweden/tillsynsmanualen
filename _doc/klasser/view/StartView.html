StartView

  • Konstruktor
  • checkStep()
  • Se även

Välkomstvy för granskare. Förklarar kortfattat granskningsprocessen och gransknings­funktionen. Innehåller också en lista på steg som granskaren behöver vidta för att komma igång; innehållet skiljer mellan det förenklade och det avancerade visningsläget.

StartView ärver från ViewBase.

Källkod
js/view/StartView.js
Enhetstester
_tests/view/StartView.test.js

Konstruktor

Syntax

new StartView(breadcrumbs, listeners, loader)

Parametrar

breadcrumbs
Länkstig (”brödsmulor”).
listeners
Händelselyssnarlista.
loader
Resursladdare.

checkStep()

Sätter markeringen för ett steg till klart/inte klart.

Syntax

checkStep(step, checked, link)

Parametrar

step
Namn på steget att markera.
checked
Flagga som anger om steget är avklarat.
link
Frågeparametrar till länken.

Returvärde

Inget (undefined).
