En komponent som presenterar en lista med alternativ och låter användaren välja ett eller flera av dem.

En instans av klassen kopplas till ett listelement (<ul>) som ska ha rollen listbox och kan ha attributet aria-multiselectable. Listelementen ska ha rollen option. Vid enkelval ska det valda elementet ha aria-selected="true"; vid flerval ska alla element ha aria-selected, med värdet antingen "true" eller "false".

Listbox implementerar designmönstret Listbox i ARIA Authoring Practices Guide.

Konstruktor

Syntax

new Listbox(listeners, keyMap)

Parametrar

listeners
Händelselyssnarlista.
keyMap
Tangentmappare.

Fält

active
Anger om listan ska reagera på händelser.

attach()

Kopplar listrutan till underliggande HTML-element i DOM-trädet och registrerar händelse­lyssnare.

Sätter aktivt element till det första elmeentet som har aria-selected="true", eller första elementet i listan om inget är valt.

Syntax

attach(list)

Parametrar

list
Lista (<ul>) som innehåller de valbara elementen.

Returvärde

Inget (undefined).

detach()

Tar bort registrerade händelselyssnare.

Syntax

detach()

Returvärde

Inget (undefined).

focus()

Sätter tangentbordsfokus till listelementet och gör angivet element till aktivt element.

Syntax

focus(index)

Parametrar

index
Index (0-baserat) för det element som ska vara aktivt. Om index anges som -1 blir sista elementet aktivt.

Returvärde

Inget (undefined).

reset()

Återställer alla valdmarkeringar i listrutan.

Vid enkelval: gör första elementet till det valda elementet.

Vid flerval: ta bort alla valdmarkeringar utom de angivna.

Gör första elementet till aktivt element, oavsett listtyp. Meddela alla registrerade observatörer om markeringsförändringar.

Syntax

reset()
reset(selected)

Parametrar

selected
Vektor med identiteter för de element som ska vara förvalda (endast flerval).

Returvärde

Inget (undefined).

subscribe()

Registrerar en observatör på listrutan. När användaren markerar eller avmarkerar element i listrutan meddelas alla registrerade observatörer.

Observatörerna anropas med ett informationsobjekt med följande fält:

state
true om elementet är markerat, annars false.
target
Det listelement vars markering ändrats.

Syntax

subscribe(notify)

Parametrar

notify
Observatör att meddela vid markeringshändelser i listrutan.

Returvärde

Inget (undefined).

unfocus()

Tar bort listan ur tangentbordsfokusordningen.

Syntax

unfocus()

Returvärde

Inget (undefined).

Tangenter

Övriga knappar (type-ahead) flyttar fokus till det element vars textinnehåll inleds med den tryckta bokstaven. Om flera bokstäver skrivs in i snabb följd konkaterneras de till en söksträng. Vid enkelval följer valdmarkeringen med fokus.

Tangentmappning för Listbox (enkelval).
Tangent Funktion
⭣ Flyttar fokus och valdmarkering till nästa element.
⭡ Flyttar fokus och valdmarkering till föregående element.
Home Flyttar fokus och valdmarkering till första element.
End Flyttar fokus och valdmarkering till sissta element.
Tangentmappning för Listbox (flerval).
Tangent Funktion
⭣ Flyttar fokus till nästa element.
⭡ Flyttar fokus till föregående element.
Home Flyttar fokus till första element.
End Flyttar fokus till sissta element.
mellanslag Växlar valdmarkering på aktivt element.
Skift+mellanslag Väljer alla element från senast valda till aktivt element.
Skift+⭣ Flyttar fokus till nästa element och växlar markering.
Skift+⭡ Flyttar fokus till föregående element och växlar markering.
Ctrl+Skift+Home Väljer alla element från första till aktivt element.
Ctrl+Skift+End Väljer alla element från aktivt element till sista.
Ctrl+A Väljer eller avmarkerar alla element.
