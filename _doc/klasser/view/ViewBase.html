Konstruktor

new ViewBase(page, title, breadcrumbs, listeners, loader)

Parametrar

Namnet på den innehållsfragmentfil som vyn ska ladda in när den öppnas (utan sökväg och filändelse).

Dokumenttitel.

Länkstig (”brödsmulor”).

Händelselyssnarlista.

Resursladdare.

Fält

action
Åtgärdssökväg (action-attributvärde) för ett formulär i det laddade sidfragmentet.

Flagga som anger om vyn ska använda det avancerade eller det förenklade visningsläget.

Länkstigen.
busy
Sätter eller tar bort attributet aria-busy på <body>-elementet.
title
Dokumenttitel.
_article
För subklasser: <article>-elementet som populerats med det laddade sidfragmentet.
_autoMenu

_doc
För subklasser: DOM-dokumentet.
_form
För subklasser: eventuellt formulärelement i det laddade sidfragmentet.
_listeners
För subklasser: händelselyssnarlista.

Sätts av subklasser: flagga för att ta bort maxbredden på <main>-elementet om det laddede sidfragmentet har brett innehåll.

activate()

Gör vyn ”aktiv” genom att lyssna efter händelser och meddela registrerade observatörer när det inträffar vissa händelser.

Metoden lägger till lyssnare för följande element och händelser:

  • klick på knappar (<button type="button">)
  • klick på länkar till andra sidor inom granskningsfunktionen
  • klick eller Enter-tryckning på statusbehållaren om den har klassen closable (hanteras internt av vyn och meddelas inte till observatörer)
  • inskick (submit) av formulär
  • ändringar av värden i formulärfält.

Syntax

activate()

Returvärde

Inget (undefined).

autoFocus()

Metoden sätter fokus till det element som har den angivna identiteten. Används med begäransparametern ”target”, då fragmentidentiferare (url#id) inte fungerar i en SPA.

Syntax

autoFocus()
autoFocus(id)

Parametrar

id
Identitet för ett specifikt element som ska få fokus (troligen från en parameter i sökvägen).

Returvärde

Inget (undefined).

close()

Stänger vyn:

  1. inaktiverar vyn (tar bort händelselyssnare)
  2. tonar bort innehållet
  3. visar statusmeddelandet ”Laddar…”
  4. tar bort eventuell automatisk innehållsmeny
  5. tar bort länkstigen
  6. tar bort eventuella tillagda stilmallar
  7. återställer maxbredden för <main>.

Syntax

close()

Returvärde

Inget (undefined).

confirm()

Visar och hanterar en modal bekräftelsedialogruta.

Dialogrutan måste existera i det laddade sidfragmentet och dess identitet måste ha satts av subklassen i det ”skyddade” fältet _confirmID.

Dialogrutan ska innehålla ett element med klassen prompt och två knappar: en OK-knapp med värdet "true" och en Avbryt-knapp med värdet "false".

Syntax

await confirm(prompt)
await confirm(prompt, trigger)
await confirm(prompt, trigger, texts)
await confirm(prompt, trigger, texts, icons)

Parametrar

prompt
Meddelande som användaren ska bekräfta.
trigger
Element (knapp) som initierat dialogrutan och ska få fokus när dialgorutan stängs.
texts
Strängvektor med alternativa knapptexter som ska ersätta texterna i mallelementet. Metoden ersätter textinnehållet i den sista underordnade noden i varje knapp med motsvarande alternativ. När dialogrutan stängs återställs knapptexterna.
icons
Flagga som kan anges som false för att dölja eventuella ikoner i dialogens knappar.

Returvärde

Ett löfte som infrias med resultatet när användaren stänger dialogrutan. Om användaren bekräftat är resultatet true, annars false.

open()

Öppnar vyn och hämtar innehållet:

  1. Lägg till <link>-element för eventuella stilmllar som en subklass specificerat genom _addStyles().
  2. Ta bort maxbredden på <main>-elementet om subklassen satt _wide=true.
  3. Hämta sidfragmentet med resursladdaren.
  4. Lägg till länkstigen, om den är komplett.
  5. Sätt dokumenttiteln.
  6. Dölj statusmeddelandet om att sidan laddar.
  7. Populera <article>-elementet med det hämtade sidfragmentets innehåll.
  8. Identifiera eventuellt formulär i sidfragmentet.
  9. Försätt sidan i antingen avancerat eller förenklat visningsläge, beroende på flaggan i fältet advancedMode.
  10. Om subklassen satt flaggan i fältet _autoMenu, skapa en automatiskt innehållsmeny.
  11. Ta bort upptagetmarkeringen (attributet aria-busy på <body>-elementet).
  12. Tona fram sidinnehållet.

Syntax

await open()

Returvärde

Ett löfte som infrias när vyn hämtat sidfragmentet och populerat artikelelementet med dess innehåll.

subscribe()

Prenumerera på händelseaviseringar från vyn.

När händelser inträffar och vyn är ”aktiv” (se activate()) meddelar vyn alla registrerade observatörer.

Syntax

subscribe(notify)

Parametrar

notify
Funktion att anropa vid avisering.

Returvärde

Inget (undefined).

Händelseinformation

De registrerade funktionerna anropas med ett händelseobjekt, vars innehåll beror på vilken typ av händelse som inträffat.

Händelseinformation vid klick på länkar till sidor i granskningsfunktionen.
Fält Värde
path Frågeparametrarna från den klickade länken.
type "link"
Händelseinformation vid ändring av värde i formulärfält.
Fält Värde
state Tillstånd (true/false) för kryssrutor och radioknappar, annars undefined.
target Elementets namn eller identitet.
type "change"
value Fältets värde (datum för datumfält och numeriskt för numeriska fält).
Händelseinformation vid knapptryckning.
Fält Värde
action Värdet i knappens value-attribut.
path null
trigger Det klickade <button>-elementet.
type "form"
Händelseinformation vid inskick av formulär.
Fält Värde
action Värdet i den aktiverande knappens value-attribut.
path Åtgärdssökväg i den aktiverande knappen (formaction) eller i formuläret (action).
trigger Den aktiverande knappen.
type "form"

_notifyAction()

Anropa alla registrerade observatörer om aktivering av en funktionsknapp (<button type="button"). Metoden anropar i sin tur _notifyObservers.

Detta är en ”skyddad” metod som bara är avsedd att anropas från subklasser.

Basklassen ViewBase hanterar funktionsknappar som existerar i DOM-trädet när metoden activate() anropas. Subklasser behöver bara anropa den här metoden om de lägger till händelsehanterare på knappar som infogas i DOM-trädet efter aktivering av vyn.

Syntax

_notifyAction(event)

Parametrar

event
Händelseinformation från DOM.

Returvärde

Inget (undefined).
