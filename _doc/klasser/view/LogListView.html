LogListView

Vy för att visa en lista med noteringarna i ärendeloggen.

LogListView ärver från ViewBase.

Källkod
js/view/LogListView.js
Enhetstester
_tests/view/LogListView.test.js

Konstruktor

Syntax

new LogListView(breadcrumbs, listeners, loader)

Parametrar

breadcrumbs
Länkstig (”brödsmulor”).
listeners
Händelselyssnarlista.
loader
Resursladdare.

Fält

create
Sökväg för att skapa en ny loggnotering.
heading
Sidrubrik.

addEntry()

Lägger till en loggnotering i listan. Metoden klonar ett mallelement (<template>) i käll­koden, populerar det resulterande dokumentfragmentet och infogar det sist i listan med loggnoteringar.

Syntax

addEntry(url, type, direction, timestamp, summary)

Parametrar

url
Länkadress för redigering av noteringen.
type
Noteringstyp (styr vilken symbol som visas för noteringen).
direction
Informationsriktning (styr vilken symbol som visas för riktningen).
timestamp
Tidsstämpel.
summary
Noteringens sammannfattning.

Returvärde

Inget (undefined).
