saveToCSVFile()

Sparar en vektor med datarader som en CSV-fil (kommaseparerade värden). Används för att spara en komprimerad version av ett granskningsprotokoll som mottagaren kan öppna och bearbeta i ett kalkylprogram, till exempel Microsoft Excel.

Syntax

saveToCSVFile(filename, data)

Parametrar

filename
Förslag på filnamn.
data
En vektor med rader att skriva till filen.

Returvärde

Inget (undefined).

saveToHTMLFile()

Sparar ett DOM-dokument som en HTML-fil. Används för att spara gransknings­protokoll, påpekanden och förelägganden så att de kan bifogas till ett e-postmeddelande.

Syntax

saveToHTMLFile(filename, dataDoc)

Parametrar

filename
Förslag på filnamn.
dataDoc
Det DOM-dokument som ska serialiseras.

Returvärde

Inget (undefined).

saveToJSONFile()

Sparar ett JavaScript-objekt som en JSON-fil. Används för att spara ett granskningsärende så att det blir åtkomligt för andra användare, och för att skydda mot dataförlust vid oav­siktlig (eller avsiktlig) radering av objektdatabasen.

Syntax

saveToHTMLFile(filename, data)

Parametrar

filename
Förslag på filnamn.
data
Det objekt som ska serialiseras.

Returvärde

Inget (undefined).

Beskrivning

Klassen tillhandahåller tre asynkrona metoder för att skriva data till fillsystemet i olika format:

  • CSV – granskningsprotokoll/åtgärdslistor
  • HTML – granskningsprotokoll, påpekanden, förelägganden
  • JSON – ärenden.

Alla tre metoderna fungerar enligt samma princip:

  1. Omvandla data som ska sparas till en Blob.
  2. Skapa en temporär data-URL för blobben.
  3. Infoga en osynlig länk till data-URL:en i webbsidan, med ett download-attribut som innehåller det föreslagna filnamnet.
  4. Simulera ett klick på länken.
  5. Frigör resurserna som allokerats för data-URL:en.

En länk med ett download-attribut öppnar i moderna webbläsare en filvalsdialog för att spara länkmålet i filsystemet. Applikationen har ingen kontroll över vad som händer sedan och vet alltså inte om användaren valt att spara filen eller avbrutit sparaoperationen. Den vet inte heller om användaren sparat filen under det föreslagna filnamnet eller valt ett annat.
