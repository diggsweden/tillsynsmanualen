ResourceLoader

  • Konstruktor
  • configuration()
  • loadModule()
  • pageContent()
  • pageTemplate()
  • resource()

Klassen ResourceLoader hämtar olika typer av resurser asynkront från servern. Den är inte, strikt sett, helt nödvändig, men möjliggör enhetstester.

Källkod
js/common/ResourceLoader.js
Enhetstester
_tests/common/ResourceLoader.test.js

Konstruktor

Syntax

new ResourceLoader()

configuration()

Hämtar en konfigurationsfil i JSON-format.

Syntax

await configuration(path)

Parametrar

path
Sökväg relativt konfigurationskatalogen (js/config/) och utan filändelse.

Returvärde

Ett löfte som infrias med ett konfigurationsobjekt skapat genom tolkning av JSON-filen när den hämtats.

Undantag

TyperError
Ett fel uppstod vid hämtning av filen från servern.

loadModule()

Importerar en JavaScript-modul.

Syntax

await loadModule(path)

Parametrar

path
Sökväg relativt controllerkatalogen (js/controller/) (med filändelse).

Returvärde

Ett löfte som infrias med den importerade modulen.

Undantag

TyperError
Ett fel uppstod vid import av modulen.
