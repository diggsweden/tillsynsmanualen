SettingStorage

Klassen SettingStorage hanterar läsning och skrivning mot web storage, det vill säga webbläsarens lokala lagringsutrymme (localStorage) och sessionslager (sessionStorage).

Källkod
js/common/SettingStorage.js
Enhetstester
_tests/common/SettingStorage.test.js

Konstruktor

Syntax

new SettingStorage()
new SettingStorage(storage)

Parametrar

storage
Lagringsutrymme att använda; standardvärdet är localStorage.

clear()

Raderarar alla nycklar i lagringsutrymmet som rör Tillsynsmanualen.

Jämför Storage.clear() som raderar alla nycklar i lagringsutrymmet för den aktuella domänen.

Syntax

clear()

Returvärde

Inget (undefined).

Undantag

TypeError
Ett fel uppstod vid radering i lagringsutrymmet.

contains()

Kontrollerar om angivna nycklar finns i lagringsutrymmet.

Syntax

contains(key1, …, keyN)

Parametrar

keyN
En eller flera lagringsnycklar att söka efter.

Returvärde

true om samtliga angivna nycklar finns i lagringsutrymmet, annars false.

read()

Läser angiven nyckel i lagringsutrymmet. Se Storage.getItem().

Syntax

read(key)

Parametrar

key
Lagringsnyckel att läsa (utan namnprefixet).

Returvärde

Det lagrade värdet för angiven nyckel, eller null om nyckeln inte finns i lagringsutrymmet.

remove()

Raderar angiven nyckel ur lagringsutrymmet. Se Storage.removeItem().

Syntax

remove(key)

Parametrar

key
Lagringsnyckel att radera (utan namnprefixet).

Returvärde

Det raderade nyckelns värde, eller null om nyckeln inte fanns i lagringsutrymmet.

write()

Lägger till eller uppdaterar angiven nyckel i lagringsutrymmet. Se Storage.setItem().

Syntax

write(key, value)

Parametrar

key
Lagringsnyckel att skriva till (utan namnprefixet).
value
Värde att lagra för den angivna nyckeln.

Returvärde

Inget (undefined).

Undantag

TypeError
Ett fel uppstod vid skrivning till lagringsutrymmet.

Beskrivning

Web storage är tacknämligt okomplicerat, men den här klassen fyller ändå en viss funktion genom att se till att alla värden applikationen lagrar har ett gemensamt namnprefix för att undvika eventuella konflikter.

Inställningar i localStorage (utan namnprefixet ”digg.manual”)
Nyckel Värde Exempel
caseDir Sökväg för ärendekatalog C:\Documents\Audits
consent Tidpunkt för samtycke till lokal lagring 1656901275581
lastPath Begäran för senast besökta sida ?page=list&type=case
mode Visningsläge: förenklat/avancerat advanced
styleFocus Tillåt formgivning av fokusmarkör false
styleFont Tillåt formgivning av teckensnitt true
