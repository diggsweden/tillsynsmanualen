KeyMap

  • Konstruktor
  • action()
  • map()
  • Exempel

Klassen KeyMap mappar tangenttryckningar till funktioner, vilket underlättar implementa­tionen av flera av designmönstren i ARIA Authoring Practices Guide.

Källkod
js/common/KeyMap.js
Enhetstester
_tests/common/KeyMap.test.js

Konstruktor

Syntax

new KeyMap()

action()

Utför den funktion som är mappad till en inträffad tangenthändelse. Metoden är avsedd att anropas från en händelselyssnare.

Syntax

action(event)

Parametrar

event
Händelseinformation från DOM.

Returvärde

true om metoden hanterat händelsen, annars false.

map()

Mappar en tangent till en funktion.

Modifierare anges som "alt", "ctrl", "meta" eller "shift", eller en kombination, till exempel "ctrl+shift".

Om tangent anges som "*" mappas funktionen som en standardfunktion och anropas för alla omappade tangenter (som genererar ett skrivbart tecken).

Detta innebär att det inte är möjligt att mappa en funktion till asterisk­tangenten.

För att mappa mellanslagstangenten, ange tangentnamn som " ".

Syntax

map(key, action)
map(key, action, modifiers)

Parametrar

key
Tangentnamn, till exempel ”A” eller ”Enter” (skiftlägesokänsligt).
action
Den funktion som ska anropas för den mappade tangenten.
modifiers
Modifierartangent(er).

Returvärde

Inget (undefined).

Exempel

const keys = new KeyMap();
keys.map("Enter", () => funcA());
keys.map("A",     () => funcB(), "ctrl+shift");

element.addventListener("keydown", (event) => {
    if (keys.action(event)) {
        event.stopPropagation();
        event.preventDefault();
    }
});

När användaren trycker Enter kommer funcA() att anropas.

När användaren trycker Ctrl+Skift+A kommer funcB() att anropas.
