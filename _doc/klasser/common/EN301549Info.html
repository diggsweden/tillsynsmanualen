EN301549Info

  • clause()
  • isWCAG()

Klassen EN301549Info har bara statiska funktioner och tillhandahåller information om kravavsnitten i EN 301 549 och WCAG.

Källkod
js/common/EN301549Info.js

clause()

Returnerar ett informationsobjekt för angivet kravavsnitt.

Syntax

EN301549Info.clause(num)

Parametrar

num
Kravavsnittsnummer i EN 301 549, till exempel ”11.1.3.1.2”.

Returvärde

Ett objekt med information om kravavsnittet, eller null om argumentet inte är ett känt kravavsnitt.

Fält i informationsobjektet

clause
Avsnittsnummer, till exempel ”9.1.2.3”.
criterion
Kriterienummer, till exempel ”1.2.3” (endast för WCAG-kriterier).
functionality
Funktionalitetstyp: "open", "closed" eller "" (endast för krav som inte ingår i WCAG).
level
Överensstämmelsenivå, till exempel ”AA” (endast för WCAG-kriterier).
title
Rubrik (kravets titel).
url
Länkadress.
wcag
true om kravet ingår i WCAG, annars false.

isWCAG()

Kontrollerar om angivet avsnittsnummer motsvarar ett kriterium i WCAG 2.1.

Syntax

EN301549Info.clause(num)

Parametrar

num
Kravavsnittsnummer i EN 301 549, till exempel ”9.1.2.3”.

Returvärde

true om numret motsvarar ett WCAG-kriterium, annars false.
