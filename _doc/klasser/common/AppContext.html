AppContext

  • Konstruktor
  • Fält
  • hasParam()
  • param()
  • reset()
  • serialize()
  • unserialize()

Klassen AppContext håller kontextuell information när användaren navigerar mellan olika sidor i granskningsfunktionen. Den ger tillgång till begäransparametrar och gör det möjligt att föra över information (till exempel statusmeddelanden) från en sida till en annan.

Källkod
js/common/AppContext.js
Enhetstester
_tests/common/AppContext.test.js

Konstruktor

Syntax

new AppContext()

Fält

advanced
Anger avancerat (true) eller förenklat (false) visningsläge. Hämtas ur parametern ”mode” eller ur en eventuell sessionskaka. Om varken parameter eller kaka är satt är fältets värde undefined.
audit
Aktuell granskningsidentitet ur sidbegäran.
caseNumber
Aktuellt ärendenummer ur sidbegäran.
error
Felmeddelande från föregående sida.
history
true om navigering sker med bakåt/framåt-knapparna i webbläsaren.
modified
true om sökvägen i kontexten förändrats jämfört med sidbegäran..
page
Sidnamn ur sidbegäran.
path
Sökväg (frågeparametrar) ur sidbegäran.
requirement
Aktuell kravidentitet ur sidbegäran.
sample
Aktuell stickprovsidentitet ur sidbegäran.
status
Statusmeddelande från föregående sida.
target
Fragmentidentifierare ur sidbegäran; antingen texten efter ”#” eller värdet i parametern ”target”.

hasParam()

Kontrollerar om angiven parameter finns angiven i sidbegäran.

Syntax

hasParam(name)

Parametrar

name
Namnet på den sökta parametern.

Returvärde

true om parametern finns i begäran, annars false.

param()

Returnerar värdet på angiven parameter i sidbegäran.

Syntax

param(name)

Parametrar

name
Namnet på den sökta parametern.

Returvärde

Värdet på den angivna parametern, eller null om den inte finns i begäran.

reset()

Återställer ändringsmarkeringen i kontexten. Markeringen sätts om fältet path sätts till ett nytt värde som inte är tomt. Den används i fördelaren för att avgöra om det är dags att lämna tillbaka kontrollen till den yttre händelseslingan.

Syntax

reset()

Returvärde

Inget (undefined).

serialize()

Skapar ett objekt som kan ”serialiseras” och återställas. Används för att spara kontexten i navigeringshistoriken.

Syntax

serialize()

Returvärde

Ett objekt med den information som krävs för att kunna återställa kontexten.

unserialize()

Återställer applikationskontexten från ett serialiserat objekt.

Syntax

unserialize(obj)

Parametrar

obj
En serialiserad applikationskontext att återställa ifrån.

Returvärde

Inget (undefined).
