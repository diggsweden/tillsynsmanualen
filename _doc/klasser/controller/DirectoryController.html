DirectoryController

  • Konstruktor

Controller för redigering av ärendekatalog.

DirectoryController ärver från ControllerBase och implementerar bara metoden prepare().

Källkod
js/controller/DirectoryController.js
Enhetstester
_tests/controller/DirectoryController.test.js

Konstruktor

Syntax

new DirectoryController(model, view)

Parametrar

model
Modellobjekt.
view
Vyinstans.

prepare()

Förbereder sidvisning minimalt: populerar länkstigen och registrerar åtgärdshanterare för spara.

Metoden hämtar och skriver ärendekatalogen i lagringsutrymmet.

Syntax

await prepare(context)

Parametrar

context
Applikationskontext.

Returvärde

Ett löfte som infrias när förberedelserna är klara.
