prepare()

Förbereder sidvisning: populerar länkstigen, registrerar en observatör på vyn och registrerar en åtgärdshanterare för att spara dokument samt populerar vyn.

Metoden hämtar ärendet ur objektdatabasen med identiteten från parametern case i sid­begäran.

Vyobservatören anropas vid klick på dokumentlänkarna i vyn och ser till att generera och visa det angivna dokumentet med hjälp av ProtocolView (granskningsprotokoll) eller RemarksView (påpkande, föreläggande).

Nedladdningsknapparna för dokumenten anropar åtgärdshanteraren för spara, som använder samma klasser för att generera dokumenten (plus CSVAuditView och CSVProtocolView) samt FileStorage för att spara dem till fil.

Användaren kan också välja att spara ärendet som en JSON-fil. Då behöver controllern populera hela ärendet (inte bara grundinformationen som vanligen visas) för att kunna spara det kompletta ärendet.

Syntax

await prepare(context)

Parametrar

context
Applikationskontext.

Returvärde

Ett löfte som infrias när förberedelserna är klara.
