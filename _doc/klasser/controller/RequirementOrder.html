Hjälpklass för hantering av kravordningen i ett stickprov.

Vilka krav som ingår i ett stickprov styrs av konfigurationsfiler. Dessa har villkorsstyrning på flera nivåer och villkorens utfall kan förändras genom redigering av stickprovet (till exempel tillägg eller borttag av innehållstyper).

Ett befintligt stickprov kan vara populerat med en tidigare konfiguration än den nu aktu­ella, till exempel när man laddat upp ett gammalt ärende från fil och konfigurationen ändrats sedan ärendet skapades.

Den inbördes ordningen mellan kraven behöver vara konsekvent i flera olika situationer – därav behovet av denna hjälpklass.

RequirementOrder sköter också om populeringen av krav i ett tomt stickprov, eftersom den processen hör intimt ihop med såväl kravordning som konfiguration.

Ett stickprov populeras med samtliga krav från konfigurationen, oavsett villkor, för att eliminera behovet av komplicerade ompopuleringar vid redigering. RequirementOrder hjälper till att hantera de krav som faktiskt ingår i gransk­ningen vid ett givet tillfälle, med hänsyn taget till villkor för urvalskategori, innehållstyper, dokumentformat, applikationsplattform och öppen/stängd funktionalitet för skärmläsare..

Konstruktor

new RequirementOrder(loader)

Parametrar

loader
Resursladdare.

[@@iterator]()

RequirementOrder är itererbar och itererar över alla kravidentiter som ingår i stickprovet.

Det är meningslöst att använda iteratorn innan ordningen byggts upp med build().

Syntax

[Symbol.iterator]()

Returvärde

En generator som itererar över alla kravidentiteter som ingår i granskningen.

Exempel

const order = new RequirementOrder(new ResourceLoader());
await order.build(sample);
for (const id of order) {
    // console.log(id);
}

build()

Hämtar den relevanta kravkonfigurationen för det angivna stickprovet och bygger krav­ordningen utifrån den. Om stickprovet inte är populerat med krav populerar metoden det.

Syntax

build(sample)

Parametrar

sample
Stickprov att bygga kravordningen för och, eventuellt, populera med krav.

Returvärde

Ett löfte som infrias med den hämtade kravkonfigurationen.

Undantag

TypeError
Det gick inte att hämta kravkonfigurationen.

next()

Returnerar den kravidentitet som följer efter den angivna referensidentiteten i ordningen.

Syntax

next(reference)

Parametrar

reference
Kravidentitet att utgå ifrån.

Returvärde

Nästa kravidentitet i ordningen, eller null om referensidentiteten är den sista.

previous()

Returnerar den kravidentitet som kommer före den angivna referensidentiteten i ordningen.

Syntax

previous(reference)

Parametrar

reference
Kravidentitet att utgå ifrån.

Returvärde

Föregående kravidentitet i ordningen, eller null om referensidentiteten är den första.

section()

Itererar över kravidentiter, i angivet konfigurationsavsnitt, som ingår i granskningen.

Syntax

section(secCfg)

Parametrar

secCfg
Avsnittskonfiguration.

Returvärde

En generator som ger de kravidentiteter i avsnittet som ingår i granskningen.

sectionless()

Itererar över avsnittslösa kravidentiter som ingår i granskningen.

Om ett stickprov innehåller ett krav som inte längre tillhör något avsnitt i konfigurationen blr dessa krav avsnittslösa. De presenteras i pseudo-avsnittet "Övrigt", efter de normala avsnitten.

Syntax

sectionless()

Returvärde

En generator som ger de kravidentiteter som ingår i granskningen, men inte tillhör något granskningsavsnitt i konfigurationen.

skip()

Returnerar identiteten för nästa ogranskade krav efter den angivna referensidentiteten i ordningen.

Syntax

skip(reference)

Parametrar

reference
Kravidentitet att utgå ifrån.

Returvärde

Identiteten för nästa krav i ordningen som inte är färdiggranskat, eller null det inte finns något sådant.
