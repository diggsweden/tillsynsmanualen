URLParameters

  • Konstruktor
  • add()
  • delete()
  • toString()
  • Exempel

En hjälpklass för att hantera frågeparametrar i en URL. Klassen ser till att skydda tecken som har särskild betydelse i en URL.

Källkod
js/controller/URLParameters.js
Enhetstester
_tests/controller/URLParameters.test.js

Konstruktor

Konstruktorn kan användas för att kopiera en befintlig instans, om man behöver två parameteruppsättningar som har både gemensamma och unika parametrar.

Syntax

new URLParameters()
new URLParameters(source)

Parameters

source
Instans att kopiera.

add()

Lägger till en parameter. Eventuella specialtecken i namnet och värdet skyddas.

Syntax

add(name)
add(name, value)

Parameters

name
Parameternamn
value
Värde.

Returvärde

Inget (undefined).

delete()

Tar bort angiven parameter.

Syntax

delete(name)

Parameters

name
Namn på parameter att ta bort.

Returvärde

Inget (undefined).

toString()

Omvandlar instansen till en sträng med parametrar åtskilda av ’&˘-tecken.

Syntax

toString()

Returvärde

Instansens parametrar åtskilda av ’&˘-tecken.

Exempel

const params = new URLParameters();
params.add("case", 42);
const edit = new URLParameters(params);
edit.add("edit");
edit.add("return", params);
console.log(params, edit);
// case=42, case=42&edit&return=case%3D42
