Controller för granskning av ett krav i ett stickprov.

RequirementController ärver från ControllerBase och implementerar bara metoden prepare().

prepare()

Förbereder sidvisning: populerar länkstigen, registrerar en observatör på vyn och registrerar en åtgärdshanterare för spara samt populerar vyn.

Metoden hämtar stickprovet ur objektdatabasen med identiteten från parametern sample i sid­begäran. Den hämtar också granskningen som stickprovet ingår i och ärendet som granskningen tillhör. Dessutom hämtar den det krav som anges via parametern requirement (indirekt; parametern ger en identitet med vars hjälp metoden kan hämta kravdata ur stickprovet vilket ger primärnyckeln för hämtning av hela kravet ur objekt­databasen).

Metoden hämtar också kravkonfigurationen för det aktuella stickprovet och populerar kravet med kontroller om det är tomt. Därefter går metoden igenom kravets alla villkor i konfigurationen och bedömer för varje villkor om det är manuellt utvärderat och i så fall till vad, eller om det är ett härlett villkor, huruvida det är uppfyllt eller inte. Detta görs med hjälp av klassen ConditionTree.

Därnäst hämtar metoden granskningskonfigurationen för kravet, som kan innehålla metodbeskrivningar, undantag, exempel, relaterad information, verktyg och tillämpings­anvisningar.

Slutligen populerar metoden vyn med alla kontroller och all information och sätter länkadresserna i navigeringen utifrån den ordning som bestäms av RequirementOrder-instansen.

Syntax

await prepare(context)

Parametrar

context
Applikationskontext.

Returvärde

Ett löfte som infrias när förberedelserna är klara.

setCheck()

Uppdaterar angiven singelkontrolls tillstånd. Metoden anropas från verktygsmoduler för att automatiskt godkänna eller underkänna kontroller utifrån data som användaren angivit i verktyget.

Syntax

setCheck(id, state)

Parametrar

id
Kontrollidentitet.
state
Tillstånd att sätta; true=godkänd, false=underkänd.

Returvärde

Inget (undefined).
