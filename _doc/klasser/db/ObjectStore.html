Kapslar in en IDBObjectStore-instans och tillhandahåller ett löftesbaserat alternativ till det händelseorienterade lågnivå-API:et.

Källkod
js/db/ObjectStore.js
Enhetstester
_tests/db/ObjectStore.test.js

Konstruktor

Syntax

new ObjectStore(store)

Parametrar

store
En IDBObjectStore-instans att kapsla in.

add()

Lägger till ett nytt värde i objektlagret. (Jämför put().)

Syntax

await add(value)
await add(value, key)

Parametrar

value
Värde att lägga till i objektlagret.
key
Extern nyckel.

Returvärde

Ett löfte som infrias med lågnivå-API:ets resultat när värdet lagts till i objektlagret. När man infogar värden i ett objektlager med autoIncrement=true returnerar exempelvis API:et den nyckel som tilldelats posten.

Exempel

const id = await store.add(obj);

count()

Räknar antalet värden i objektlagret.

Syntax

await count()
await count(count, query)

Parametrar

query
En nyckel eller ett IDBKeyRange-objekt som anger ett nyckelintervall att räkna inom.

Returvärde

Ett löfte som infrias med det räknade antalet värden.

delete()

Raderar angivna värden ur objektlagret.

Syntax

await delete(keys)

Parametrar

keys
En nyckel eller ett IDBKeyRange-objekt som anger ett nyckelintervall att radera.

Returvärde

Ett löfte som infrias när värdena raderats.

get()

Hämtar angivet värde ur objektlagret.

Syntax

await get(key)

Parametrar

key
Ett nyckelvärde.

Returvärde

Ett löfte som infrias med det hämtade värdet.

getAll()

Hämtar alla eller angivna värden ur objektlagret.

Syntax

await getAll()
await getAll(query)
await getAll(query, count)

Parametrar

query
En nyckel eller ett IDBKeyRange-objekt som anger ett nyckelintervall att hämta.
count
Maximalt antal värden att hämta.

Returvärde

Ett löfte som infrias med de hämtade värdena.

index()

Öppnar ett index i objektlagret.

Syntax

index(name)

Parametrar

name
Namn på det index som ska öppnas.

Returvärde

En Index-instans som kapslar in det IDBIndex-objekt som lågnivå-API:et returnerar.

openCursor()

Öppnar en cursor i objektlagret.

Syntax

openCursor()
openCursor(query)
openCursor(query, direction)

Parametrar

query
En nyckel eller ett IDBKeyRange-objekt som anger ett nyckelintervall att iterera över.
direction
Cursorns riktning (standardvärde "next").

Returvärde

En Cursor-instans som kapslar in det IDBCursorWithValue-objekt som lågnivå-API:et returnerar.

openKeyCursor()

Öppnar en nyckel-cursor i objektlagret.

Syntax

openKeyCursor()
openKeyCursor(query)
openKeyCursor(query, direction)

Parametrar

query
En nyckel eller ett IDBKeyRange-objekt som anger ett nyckelintervall att iterera över.
direction
Cursorns riktning (standardvärde "next").

Returvärde

En Cursor-instans som kapslar in det IDBCursor-objekt som lågnivå-API:et returnerar.

put()

Lägger till eller uppdaterar ett värde i objektlagret. (Jämför add().)

Syntax

await put(value)
await put(value, key)

Parametrar

value
Värde att spara i objektlagret.
key
Extern nyckel.

Returvärde

Ett löfte som infrias när värdet sparats i objektlagret.
