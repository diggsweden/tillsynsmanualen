Transaction

  • Konstruktor
  • complete()
  • objectStore()
  • Se även

Kapslar in en IDBTransaction-instans och tillhandahåller ett löftesbaserat alternativ till det händelseorienterade lågnivå-API:et.

Källkod
js/db/Transaction.js
Enhetstester
_tests/db/Transaction.test.js

Konstruktor

Syntax

new Transaction(tx)

Parametrar

tx
En IDBTransaction-instans att kapsla in.

complete()

Inväntar en complete-händelse från den underliggande transaktionen.

Syntax

await complete(payload)

Parametrar

payload
Eventuell ”nyttolast” som förmedlas näar löftet infrias.

Returvärde

Ett löfte som infrias med eventuell angiven ”nyttolast” när transaktionen slutförs.

Exempel

const tx = db.transaction(["store"]);
// …
await tx.complete();

objectStore()

Returnerar angivet objektlager som ingår i transaktionen.

Syntax

objectStore(name)

Parametrar

name
Namnet på det önskade objektlagret.

Returvärde

En ObjectStore-instans som kapslar in det IDBObjectStore-objekt som lågnivå-API:et returnerar.

Exempel

const tx = db.transaction(["store"]);
const store = tx.objectStore("store");
const result = store.getAll();
await tx.complete();
