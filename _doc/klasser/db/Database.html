open()

Öppnar en anslutning till databasen

Skapar ett IDBOpenDBRequest genom att anropa IDBFactory.open() och registrerar händelselyssnare på det.

Om en uppgraderingshändelse inträffar anropar metoden den angivna uppgraderings­funktionen med ett IDBVersionChangeEvent som argument.

Syntax

await open(name)
await open(name, version)
await open(name, version, upgrade)

Parametrar

name
Databasnamn ("monitoringManual").
version
Versionsnummer.
upgrade
Funktion att anropa vid uppgradering. Funktionen anropas med ett argument (IDBVersionChangeEvent) och förväntas returnera true om uppgraderingen går bra.

Returvärde

Ett löfte som infrias med instansen när databasanslutningen öppnats (efter eventuell uppgradering). Vid fel från underliggande API avslås löftet.

transaction()

Skapar en transaktion i databasen.

Syntax

transaction(storeNames)
transaction(storeNames, mode)
transaction(storeNames, mode, options)

Parametrar

storeNames
En vektor med namnen på de objektlager som ska ingå i transaktionen.
mode
Åtkomstläge: "readonly" (standard) eller "readwrite".
options
Parametrar; se IDBDatabase.transaction().

Returvärde

En Transaction-instans som kapslar in en IDBTransaction-instans.
