Kapslar in en IDBCursor-instans och tillhandahåller ett löftesbaserat alternativ till det händelseorienterade lågnivå-API:et.

Klassen implementerar också protokollen iterable och iterator, vilket innebär att den går att använda i en for await…of-loop.

Källkod
js/db/Cursor.js
Enhetstester
_tests/db/Cursor.test.js

Konstruktor

Syntax

new Cursor(request)

Parametrar

request
En IDBRequest-instans som typiskt kommer från ett anrop till openCursor() i en instans av Index eller ObjectStore.

Fält

direction
Cursorns iterationsriktning.
key
Aktuell nyckel.
primaryKey
Aktuell primärnyckel.
source
Cursorns källa.
value
Aktuellt värde.

advance()

Avanerar cursorn angivet antal steg.

Syntax

advance(count)

Parametrar

count
Antal steg att avancera cursorn.

Returvärde

Inget (undefined).

continue()

Avancerar cursorn ett steg, eller till angiven nyckel.

Syntax

continue()
continue(key)

Parametrar

key
Nyckel att positionera cursorn vid.

Returvärde

Inget (undefined).

continuePrimaryKey()

Positionera cursorn vid angivna nycklar

Syntax

continue(key, primaryKey)

Parametrar

key
Nyckel att positionera cursorn vid.
primaryKey
Primärnyckel att positionera cursorn vid.

Returvärde

Inget (undefined).

delete()

Radera värdet vid cursorns position.

Metoden är inte tillgänglig i en cursor som öppnats med openKeyCursor().

Syntax

await delete()

Returvärde

Ett löfte som infrias när värdet tagits bort.

next()

Avancera iteratorn ett steg, asynkront, genom att invänta nästa händelse i cursorbegäran.

Syntax

await next()

Returvärde

Ett löfte som infrias med ett IteratorResult-objekt när cursorn avancerats.

update()

Uppdatera värdet vid cursorns position.

Metoden är inte tillgänglig i en cursor som öppnats med openKeyCursor().

Syntax

await update(value)

Parametrar

value
Värde att uppdatera med.

Returvärde

Ett löfte som infrias när värdet uppdaterats.

Exempel

const cursor = index.openCursor();
for await (const record of cursor) {
    // console.log(record.value);
}
