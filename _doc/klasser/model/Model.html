Klassen Model utgör modellen i applikationen och representerar de data som applikationen hanterar. Data kan vara flyktiga (leva bara medan webbläsarsessionen är öppen) eller permanenta – lagrade i webbläsarens lagringsutrymme (localStorage) eller objektdatabas (indexedDB).

Konstruktor

Syntax

new Model(database, settings)

Parametrar

database
Gränssnitt mot objektdatabasen.
settings
Gränssnitt mot lagringsutrymmet för inställningar.

Fält

advancedMode
Flagga som anger om applikationen ska använda det avancerade visningsläget (true) eller det förenklade (false). Flaggan hämtas och sparas i inställningslagret.
caseDirectory
Sökväg till ärendekatalogen under vilken granskningsärenden sparas i filsystemet. Värdet hämtas och sparas i inställningslagret.
confirmComponents
Flagga som anger om applikationen ska visa en dialogruta där granskaren får bekräfta komponentkopplingar vid spara nytt urval. (Standardvärdet, om ej satt, är true.)
lastPath
Frågeparametrar från senast sparade sidbegäran i granskningsfunktioneen. Värdet hämtas och sparas i inställningslagret.

getAudit()

Hämtar en granskning och de ingående stickproven (men inte deras krav och kontroller, som standard).

Syntax

await getAudit(id)
await getAudit(id, recursive)

Parametrar

id
Granskningens identitet i databasen.
recursive
Om true populeras stickproven med krav och kraven med kontroller. Standardvärdet är false.

Returvärde

Ett löfte som infrias med en Audit-instans som representerar granskningen, eller null om ingen granskning med angiven identitet finns i databasen.

Undantag

Error
Databastransaktionen misslyckades.

populate()

Populerar ett ärende med alla uppgifter. Används när man vill spara ett komplett ärende som JSON-fil.

Metoden utgår från att ärendet är populerat med granskningar och populerar varje granskning med stickprov. Varje stickprov populeras med krav, som i sin tur populeras med kontroller.

Syntax

await populate(aCase)

Parametrar

aCase
Ärende att populera.

Returvärde

Ett löfte som infrias när ärendet är populerat.

Undantag

Error
Databastransaktionen misslyckades.
