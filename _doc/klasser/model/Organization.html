Organization

Klassen Organization innehåller uppgifter om den aktör som ansvarar för en granskad digital service. Vissa uppgifter visas bara i det avancerade visningsläget, eftersom de bara är relevanta vid tillsyn.

Källkod
js/model/Organization.js
Enhetstester
_tests/model/Organization.test.js

Konstruktor

Om ett dataobjekt anges som argument populerar konstruktorn instansen med informa­tionen i det. Det används vid återställning av ett ärende när det hämtas från objektdata­basen eller när ett sparat ärende i JSON-format läses in från fil.

Syntax

new Organization()
new Organization(data)

Parametrar

data
Dataobjekt att populera instansen med.

Fält

abbreviation
En förkortning av organisationsnamet, till exempel ”DIGG” för ”Myndigheten för digital förvaltning”. Används i påpekanden och förelägganden, och visas därför inte i det förenklade visningsläget.
address
Aktörens postadress (gatuadress, postnummer och ort). Kan behöva användas om en aktör inte svarar på e-post.
email
E-postadress. Vid tillsyn används i första hand ”registrator@myndighet.se”.
name
Den granskade aktörens namn, exempelvis namnet på en kommun eller myndighet.
registrationNumber
Organisationsnummer. Används i påpekanden och förelägganden, och visas därför inte i det förenklade visningsläget.
telephone
Telefonnummer, inklusive riktnummer.

Klassen använder RegistrationNumber och TelephoneNumber internt för validering och formatering, men åtkomstmetoderna för fälten hanterar dem som strängar.

serialize()

Skapar ett objekt som kan ”serialiseras” och återställas. Används när ett ärende sparas i databasen.

Syntax

serialize()

Returvärde

Ett objekt med den information som krävs för att kunna återställa organisationsinformationen.

toJSON()

Skapar ett objekt som kan ”serialiseras” och återställas. Används när ett ärende sparas till fil.

Syntax

toJSON()

Returvärde

Ett objekt med den information som krävs för att kunna återställa organisationsinformationen.
