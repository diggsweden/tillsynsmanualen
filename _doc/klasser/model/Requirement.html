Klassen Requirement representerar ett krav som ska kontrolleras i ett stickprov som ingår i urvalet i en granskning i ett granskningsärende.

Ett krav består av en eller flera kontroller och kan ha villkor som styr om det ska ingå i granskningen eller inte. Villkoren anges i konfigurationen och utvärderas av kravinstansen.

Villkorsstyrning av krav.
Villkor Kravet ingår om det tillhör…
categories ett stickprov i någon av de angivna urvalskategorierna.
contentTypes ett stickprov med någon av de angivna innehållstyperna.
formats ett dokument med något av de angivna formaten.
platforms en vy i en mobil applikation på någon av de angivna plattformarna.

key

by_sample / sampleID

Ett krav kan godkännas utan granskning (”automatiskt godkännande”). Granskaren kan tillämpa automatiskt godkännande för krav som uppenbart är uppfyllda för alla stickprov, exempelvis på en mallbaserad webbplats. Ett automatiskt godkännande kan dras tillbaka om det visar sig att stickprovet avviker från normen.

Konstruktor

Om ett dataobjekt anges som argument populerar konstruktorn instansen med informa­tionen i det. Det används vid återskapande av ett objekt när det hämtas från objektdata­basen eller när ett sparat ärende i JSON-format läses in från fil.

Syntax

new Requirement(sampleID)
new Requirement(sampleID, data)

Parametrar

sampleID
Identitet för det stickprov som kravet ingår i.
data
Dataobjekt att populera instansen med.

Undantag

TypeError
Ingen stickprovsidentitet angiven.
Dataobjektet hör inte till det angivna stickprovet.

Fält

approvable
true om kravet ska gå att godkänna utan granskning, annars false.
approved
true om kravet har godkänts utan granskning, annars false.
categories
Villkor för urvalskategorier.
clause
Kravavsnittsnummer (i EN 301 549, DOS-lagen eller föreskriften).
contentTypes
Villkor för innehållstyper.
dependencies
Funktion för att hämta krav; sätts i och anropas av härledda kontroller. Kravklassen förmedlar bara funktionen. Se DerivedCheck.
done
Flagga som anger om kravet är färdiggranskat (state är skilt från null).
externalNote
Anteckning som ska visas i granskningsprotokollet.
failed
Flagga som anger om ett färdiggranskat krav är underkänt (state är false).
hasChecks
Flagga som anger om kravet är populerat med kontroller.
id
Kravets identitet i konfigurationen.
internalNote
Anteckning som ska visas i granskningsprotokollet.
key
Primärnyckel i databasen.
platforms
Villkor för plattformar (operativsystem).
sampleID
Stickprovsidentitet.
state
Kravets tillstånd: undefined om någon kontroll har obestämt tillstånd, false om någon kontroll är underkänd, annars true. Icke tillämpliga kontroller och härledda kontroller som bara används för att styra härledda villkor har ingen inverkan på kravtillståndet.
title
Kravets titel.

check()

Returnerar kontrollen med angiven identitet.

Syntax

 check(id)

Parametrar

id
Kontrollidentitet.

Returvärde

Kontrollen med angiven identitet, om den ingår i kravet, annars undefined.

checks()

Itererar över de kontroller som ingår i kravet.

Syntax

checks()

Returvärde

Ett generatorobjekt som ger en Check-instans vid varje anrop.

Example

for (const check of requirement.checks()) {…}

matchCategory()

Kontrollerar om kravet matchar filtervillkoren för urvalskategori.

Syntax

matchCategory(category)

Parametrar

category
Urvalskategori att matcha.

Returvärde

true om kravet ska ingå i ett stickprov i angiven urvalskategori, annars false.

matchContentTypes()

Kontrollerar om kravet matchar filtervillkoren för innehållstyper.

Syntax

matchContentTypes(types)

Parametrar

types
Vektor med innehållstyper att matcha.

Returvärde

true om kravet ska ingå i ett stickprov med någon av de angivna innehållstyperna, annars false.

matchFormat()

Kontrollerar om kravet matchar filtervillkoren för dokumentformat.

Syntax

matchFormat(format)

Parametrar

format
Format att matcha.

Returvärde

true om kravet ska ingå i ett dokument i det angivna formatet, annars false.

matchPlatform()

Kontrollerar om kravet matchar filtervillkoren för applikationsplattform.

Syntax

matchPlatform(platform)

Parametrar

platform
Plattform att matcha.

Returvärde

true om kravet ska ingå i en vy i en mobil applikation på den angivna plattformet, annars false.

serialize()

Skapar ett objekt som kan ”serialiseras” och återskapas. Används när ett objekt sparas i databasen.

Kontrollerna ingår inte i serialiseringen, eftersom de lagras i ett eget objektlager och sparas separat.

Syntax

serialize()

Returvärde

Ett objekt med den information som krävs för att kunna återskapa kravinformationen.

setCheck()

Lägger till eller uppdaterar en kontroll i stickprovet.

Syntax

setCheck(check)

Parametrar

check
Kontroll att lägga till eller uppdatera.

Returvärde

Inget (undefined).

Undantag

TypeError
Kontrollidentitet saknas eller är tom.

toJSON()

Skapar ett objekt som kan ”serialiseras” och återskapas. Används när ett ärende sparas till fil.

Kontrollerna ingår i serialiseringen, eftersom all information som hör till ärendet behöver ingå i filen för att informationen ska gå att återskapa.

Syntax

toJSON()

Returvärde

Ett objekt med den information som krävs för att kunna återskapa kravinformationen.

toString()

Omvandlar kravet till en sträng.

Syntax

toString()

Returvärde

Kravets identitet i konfigurationen.
