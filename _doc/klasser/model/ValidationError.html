ValidationError

Klassen ValidationError utökar klassen Error och representerar ett fel vid validering av data som användaren matat in.

Källkod
js/model/ValidationError.js

Konstruktor

Syntax

new ValidationError(message, value)

Parametrar

message
Felmeddelande.
value
Det ogiltiga värdet.
