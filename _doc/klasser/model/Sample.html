Basklassen Sample representerar ett stickprov i en granskning i ett granskningsärende.

Ett stickprov innehåller ett antal krav. Vilka krav som ingår är konfigurationsstyrt och beror på vilken typ av stickprov det är och vilken typ av innehåll stickprovet har.

Ett stickprov kan ingå i en process och då ska alla steg i den processen granskas enligt kommissionens genomförandebeslut (EU) 2018/1524 om övervakning av digital offentlig service. Den inbördes ordningen mellan stegen i en sådan process uttrycks genom att granskaren anger vilket stickprov som ”följer” vilket.

Vid urvalet kan granskaren göra en notering, som visas i granskningsöversikten och på stickprovets kravöversikt.

Ett stickprov ingår i en av de kategorier som definieras i ovannämnda genomförandebeslut (eller den speciella kategorin ”komponenter”).

Stickprovet har också en uppsättning innehållstyper som talar om vilka typer av innehåll som ingår. Detta styr, via konfigurationsfiler, vilka krav stickprovet populeras med.

Konstruktor

Om ett dataobjekt anges som argument populerar konstruktorn instansen med informa­tionen i det. Det används vid återskapande av ett objekt när det hämtas från objektdata­basen eller när ett sparat ärende i JSON-format läses in från fil.

Om dataobjektet är en instans av Sample (eller en subklass) kopieras den. Det används när granskaren väljer att kopiera en tidigare granskning vid omgranskning, för att slippa göra om urvalet.

Syntax

new Sample(auditID, category)
new Sample(auditID, source)
new Sample(auditID, data)

Parametrar

auditID
Identitet för den granskning som stickprovet ingår i.
category
Namnet på den urvalskategori stickprovet ingår i.
source
Källa (stickprov) att kopiera.
data
Dataobjekt att populera instansen med.

Undantag

TypeError
Ingen granskningsidentitet angiven.
Ingen urvalskategori angiven.
Dataobjektet hör inte till den angivna granskningen.

Fält

auditID
Granskningsidentitet.
category
Urvalskategori.
contentTypes
Innehållstyper.
done
Flagga som anger om stickprovet är färdiggranskat. Ett stickprov markerat med partiell granskning anses alltid färdiggranskat.
failed
Flagga som anger om ett färdiggranskat stickprov är underkänt.
follows
Anger namnet på det stickprov som föregår det aktuella stickprovet i en process.
hasExternalNotes
Flagga som anger om ett eller flera krav har en extern anteckning.
hasRequirements
Flagga som anger om stickprovet är populerat med krav.
id
Identitet i databasen.
name
Stickprovets namn eller titel.
note
Granskarens notering vid urvalet.
partial
Flagga som anger om stickprovet ska granskas partiellt.
service
Den ”typ av tjänst” stickprovet tillhör om det ingår i kategorin service.
started
Flagga som anger om granskningen av stickprovet påbörjats.

addContentType()

Lägger till en innehållstyp. Innehållstyper anger vilka typer av innehåll som ingår i stickprovet och styr, via konfigurationsfiler, vilka krav som granskaren ska kontrollera.

Syntax

addContentType(type)

Parametrar

type
Innehållstypsidentitet att lägga till. Ska motsvara någon av de innehållstyper som definierias i kravkonfigurationen för stickprovet.

Returvärde

Inget (undefined).

Undantag

TypeError
Innehållstypsidentitetn saknas eller är tom.

contains()

Kontrollerar om stickprovet innehåller någon av de angivna innehållstyperna.

Syntax

addContentType(type1, …, typeN)

Parametrar

typeN
Innehållstypsidentitet att söka efter.

Returvärde

true om minst en av de angivna innehållstyperna ingår i stickprovet, annars false.

deleteContentType()

Tar bort angiven innehållstyp ur stickprovet.

Syntax

deleteContentType(type)

Parametrar

type
Innehållstypsidentitet att ta bort.

Returvärde

true om den angivna innehållstypen ingick i stickprovet och har tagits bort, annars false.

failures()

Returnerar underkända kravavsnittsnummer. Metoden anropas av Audit.failures() med ett mängdobjekt (Set) som den populerar med avsnittsnumren för alla underkända krav i stickprovet.

Syntax

failures(fails)

Parametrar

fails
Mẅngden av underkända kravavsnitt för stickprovet.

Returvärde

Det populerade mängdobjektet.

nextRequirement()

Returnerar nästa krav att granska.

Syntax

nextRequirement()

Returvärde

Det första kravet som inte är färdiggranskat, eller undefined om alla krav är färdiggranskade.

progress()

Returnerar antalet granskade krav och det totala antalet krav (med hänsyn taget till eventuella filter).

Syntax

progress()

Returvärde

En vektor med två tal: antal granskade krav och totalt antal krav.

requirement()

Returnerar kravet med angiven identitet, om det ska ingå i granskningen.

Syntax

requirement(id)

Parametrar

id
Kravidentitet.

Returvärde

Kravet med angiven identitet, om det ingår i stickprovet och matchar eventuella villkor för urvalskategori, innehållstyper, dokumentformat och applikationsplattform, annars null.

requirements()

Itererar över de krav som ingår i stickprovet, med hänsyn taget till eventuella filter.

Syntax

requirements()
requirements(all)

Parameters

all
Flagga som anger om alla krav, oavsett filter, ska ingå i iterationen. Standardvärdet är false, vilket innebär att metoden bara itererar över tillämpliga krav.

Returvärde

Ett generatorobjekt som ger en Requirement-instans vid varje anrop.

Example

for (const req of sample.requirements()) {…}

serialize()

Skapar ett objekt som kan ”serialiseras” och återskapas. Används när ett objekt sparas i databasen.

Kraven ingår inte i serialiseringen, eftersom de lagras i ett eget objektlager och sparas separat.

Syntax

serialize()

Returvärde

Ett objekt med den information som krävs för att kunna återskapa stickprovsinforma­tionen.

setRequirement()

Lägger till eller uppdaterar ett krav i stickprovet.

Syntax

setRequirement(requirement)

Parametrar

requirement
Krav att lägga till eller uppdatera.

Returvärde

Inget (undefined).

Undantag

TypeError
Kravidentitet saknas eller är tom.

toJSON()

Skapar ett objekt som kan ”serialiseras” och återskapas. Används när ett ärende sparas till fil.

Kraven ingår i serialiseringen, eftersom all information som hör till ärendet behöver ingå i filen för att informationen ska gå att återskapa.

Syntax

toJSON()

Returvärde

Ett objekt med den information som krävs för att kunna återskapa stickprovsinforma­tionen.

toString()

Omvandlar granskningen till en sträng.

Syntax

toString()

Returvärde

Stickprovets namn eller titel.
