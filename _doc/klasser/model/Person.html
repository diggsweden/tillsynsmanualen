Klassen Person representerar en person vars uppgifter behöver refereras till då och då: handläggare och, vid tillsyn, tillsynsansvariga.

Källkod
js/model/Person.js
Enhetstester

Objektlager

Primärnyckel
id

Konstruktor

Om ett dataobjekt anges som argument populerar konstruktorn instansen med informa­tionen i det. Det används vid återskapande av ett objekt när det hämtas från objektdata­basen eller när ett sparat ärende i JSON-format läses in från fil.

Syntax

new Person()
new Person(data)

Parametrar

data
Dataobjekt att populera instansen med.

Fält

email
E-postadress.
familyName
Efternamn.
giveName
Förnamn.
id
Identitet i databasen (kan sättas, men inte ändras).
name
Hela namnet (Efternamn, Förnamn); jämför toString().
roles
En vektor med de roller personen innehar. De roller som används är "officer" (handläggare) och "supervisor" (tillsynsansvarig).
telephone
Telefonnummer.

E-postadressen används som nyckel i databasen och är därför obligatorisk.

Klassen använder TelephoneNumber internt för validering och formatering, men åtkomstmetoderna för fältet hanterar det som en sträng.

addRole()

Lägger till en roll för personen.

Syntax

addRole(role)

Parametrar

role
Roll att lägga till.

Returvärde

Inget (undefined).

deleteRole()

Tar bort angiven roll från personen.

Syntax

deleteRole(role)

Parametrar

role
Roll att ta bort.

Returvärde

Inget (undefined).

hasRole()

Kontrollerar om personen har angiven roll.

Syntax

hasRole(role)

Parametrar

role
Roll att kontrollera.

Returvärde

true om personen har den angivna rollen, annars false.

serialize()

Skapar ett objekt som kan ”serialiseras” och återskapas. Används när ett objekt sparas i databasen.

Syntax

serialize()

Returvärde

Ett objekt med den information som krävs för att kunna återskapa personinformationen.

toJSON()

Skapar ett objekt som kan ”serialiseras” och återskapas. Används när ett ärende sparas till fil.

Syntax

toJSON()

Returvärde

Ett objekt med den information som krävs för att kunna återskapa personinformationen.

toString()

Omvandlar ett personobjekt till en sträng.

Syntax

toString()

Returvärde

En sträng på formen ”Förnamn Efternamn” (jämför fältet name).
