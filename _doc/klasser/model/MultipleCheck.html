MultipleCheck

  • Konstruktor
  • Fält
  • fail()

  • Se även

Klassen MultipleCheck utökar basklassen Check och representerar en ”multipel” kontoll i ett krav som ingår i ett stickprov i en granskning i ett granskningsärende.

En multipel kontroll består av två eller fler alternativa påståenden. Om något alternativ är godkänt är kontrollen godkänd. Bara om alla alternativ är underkända blir alltså kontrollen som helhet underkänd och kan ha en tillhörande observation.

Konstruktor

Om ett dataobjekt anges som argument populerar konstruktorn instansen med informa­tionen i det. Det används vid återskapande av ett objekt när det hämtas från objektdata­basen eller när ett sparat ärende i JSON-format läses in från fil.

Förutom den återställning som basklasskonstruktorn utför:

  • Om dataobjektet innehåller fältet ok, sätt applicable till true, disabled till false och alla delkontroller till godkända;
  • annars, om dataobjektet innehåller fältet m (mask), använd värdet som en bitmask där varje bit som är 1 motsvarar en underkänd delkontroll och varje bit som är 0 en godkänd samt sätt applicable till true och disabled till false;
  • annars, om dataobjektet innehåller fältet obs (observation), sätt alla delkontroller till underkända.

Syntax

new MultipleCheck(reqID, count)
new MultipleCheck(reqID, data)

Parametrar

reqID
Identitet för det krav som kontrollen ingår i.
count
Antal alternativ i kontrollen.
data
Dataobjekt att populera instansen med.

Undantag

TypeError
Antalet alternativ är <2 eller >32.

Fält

cardinality
Antalet alternativ i kontrollen.
state
En flagga som anger om kontrollen är godkänd (true) eller underkänd (false). Om kontrollen inte är granskad eller inte är tillämplig har flaggan värdet undefined.

fail()

Underkänner eller godkänner ett alternativ i kontrollen.

Syntax

fail(index, flag)

Parametrar

index
Index (0-baserat) för alternativet.
flag
Underkänn (true) eller godkänn (false).

Returvärde

Inget (undefined).

Undantag

TypeError
Inget alternativ med angivet index finns i kontrollen.

fails()

Kontrollerar om angivet alternativ är underkänt eller godkänt.

Syntax

fails(index)

Parametrar

index
Index (0-baserat) för alternativet.

Returvärde

true om det angivna alternativet är underkänt, annars false.

Undantag

TypeError
Inget alternativ med angivet index finns i kontrollen.

serialize()

Skapar ett objekt som kan ”serialiseras” och återskapas. Används när ett objekt sparas i databasen.

Eftersom en granskning kan innehålla ett stort antal kontroller används ett kompakt format vid serialisering: bara precis så mycket som behövs för att kunna återskapa instansen.

Lägg till i det objekt som basklassmetoden serialiserat:

  • Fältet n med kontrollens kardinalitet (antalet delkontroller).
  • Fältet ok med värdet true om alla delkontroller är godkända;
  • annars, om några, men inte alla, delkontroller är underkända, fältet m (mask) som en bitmask där varje underkänd delkontroll representeras av en bit med värdet 1 och varje godkänd delkontroll av en bit med värdet 0.

Syntax

serialize()

Returvärde

Ett objekt med den information som krävs för att kunna återskapa kontrollinformationen.
