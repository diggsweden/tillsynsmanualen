DerivedCheck

  • Konstruktor
  • Fält
  • dependsOn()
  • serialize()
  • Se även

Klassen DerivedCheck utökar basklassen Check och representerar ett ”härlett” krav som inte godkänns eller underkänns explicit av granskaren utan härleds från ett eller flera andra krav i samma stickprov.

En härledd kontroll kan vara "global", vilket innebär att dess beroenden även ska omfatta eventuella komponenter som ingår i stickprovet. Normalfallet är att beroendena bara omfattar kraven i själva stickprovet.

Klassen behöver hämta beroenden för att kunna utvärdera dem. Fältet dependencies ska sättas till en funktion som anropas med en kravidentitet och en globalflagga och returne­rar en vektor av "underkännbara” objekt (i praktiken krav). Detta för att undvika hårda beroenden mellan klasser.

Konstruktor

Om ett dataobjekt anges som argument populerar konstruktorn instansen med informa­tionen i det. Det används vid återskapande av ett objekt när det hämtas från objektdata­basen eller när ett sparat ärende i JSON-format läses in från fil.

Förutom den återställning som basklasskonstruktorn utför:

  • Sätt källkravsidentiteter från vektorfältet dep (dependencies).
  • Sätt globalflaggan i enlighet med fältet global, om det finns i dataobjektet.

Syntax

new Check(reqID, sample)
new Check(reqID, sample, data)

Parametrar

reqID
Identitet för det krav som kontrollen ingår i.
sample
Det stickprov som kravet ingår i.
data
Dataobjekt att populera instansen med.

Fält

control
En flagga som anger om kontrollen används enbart för att styra ett härlett villkor, och inte ska påverka kravets tillstånd. Värdet är true om kontrollens observation är tom, annars false.
dependencies
En callback-funktion som anropas med en kravidentitet och en globalflagga och förväntas returnera en vektor av krav. Vektorn har bara ett element om globalflaggan inte är satt. (Endast skrivning.)
derived
Alltid true; används för att identifiera härledda kontroller.
global
En flagga som anger om kontrollen är ”global”, det vill säga även ska omfatta krav som hör till komponenter som ingår i stickprovet. Standardvärdet är false.
state
En flagga som anger om kontrollen är godkänd (true) eller underkänd (false). Om kontrollen inte är granskad eller inte är tillämplig har flaggan värdet undefined.

dependsOn()

Lägger till identiteten för ett krav (i samma stickprov) som kontrollen ska härledas ifrån.

Syntax

dependsOn(id)

Parametrar

id
Kravets identitet i konfigurationen.

Returvärde

Inget (undefined).

serialize()

Skapar ett objekt som kan ”serialiseras” och återskapas. Används när ett objekt sparas i databasen.

Lägg till i det objekt som basklassmetoden serialiserat:

  • Vektorfältet dep (dependencies) med identiteterna för de krav som kontrollen är härledd ifrån.
  • Flaggan control om villkorsstyrflaggan är satt.
  • Flaggan global om globalflaggan är satt.

Syntax

serialize()

Returvärde

Ett objekt med den information som krävs för att kunna återskapa kontrollinformationen.
