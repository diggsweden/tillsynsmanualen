ComplaintCase

  • Konstruktor
  • Fält
  • serialize()
  • Se även

Klassen ComplaintCase utökar AuditCase (granskningsärende) och representerar ett anmälningsärende till tillsynsmyndigheten. Klassen används bara i det avancerade visningsläget.

Anmälningsärendet utökar granskningsärendet med ett datum för beslut om tillsyn och information om tillsynsansvarig som fattade beslutet.

Källkod
js/model/case.js
Enhetstester
_tests/model/case.test.js
Objektlager
cases
Primärnyckel
id

Konstruktor

Om ett dataobjekt anges som argument populerar konstruktorn instansen med informa­tionen i det. Det används vid återskapande av ett objekt när det hämtas från objektdata­basen eller när ett sparat ärende i JSON-format läses in från fil.

Syntax

new ComplaintCase()
new ComplaintCase(data)

Parametrar

data
Dataobjekt att populera instansen med.

Fält

date
Datum för beslut om tillsyn.
monitoring
Tillsynsflagga (true).
sections
De paragrafnummer som utgör den rättsliga grunden för ett anmälningsärende (16 och 18 §§ DOS-lagen).
supervisor
Information om tillsynsansvarig som beslutat om tillsyn.
type
Ärendetyp ("complaint").

serialize()

Skapar ett objekt som kan ”serialiseras” och återskapas. Används när ett objekt sparas i databasen.

Metoden utökar basklassens metod genom att inkludera beslutsdatum och tillsynsansvarig.

Syntax

serialize()

Returvärde

Ett objekt med den information som krävs för att kunna återskapa ärendeinformationen.
