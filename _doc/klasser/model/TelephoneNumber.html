TelephoneNumber

  • Konstruktor
  • toString()
  • Se även

Klassen TelephoneNumber representerar ett telefonnummer, inklusive riktnummer, och har två syften: att validera numret vid inmatning och att formatera det vid utmatning.

Källkod
js/model/TelephoneNumber.js
Enhetstester
_tests/model/TelephoneNumber.test.js

Konstruktor

Konstruktorn validerar det angivna telefonnumret och kastar ett undantag om det inte är giltigt.

Syntax

new TelephoneNumber(numberString)

Parametrar

numberString
Telefonnumret i strängform.

Undantag

ValidationError
Telefonnumret består inte av 8–10 siffror eller börjar inte med ett korrekt riktnummer.

toString()

Omvandlar telefonnumret till en sträng.

Syntax

toString()

Returvärde

Ett telefonnummer formaterat enligt standard för svenska telefonnummer
