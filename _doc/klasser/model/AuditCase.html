Klassen AuditCase representerar ett granskningsärende och är den ärendeklass som används i det förenklade visningsläget.

Det innehåller information om den digitala service som granskas, i form av en instans av en klass härledd från Service, och om den aktör som ansvarar för den (genom en Organization-instans).

Ärendet innehåller också noteringarna i ärendeloggen., som instanser av LogEntry.

Sist men inte minst innehåller ärendet de granskningar (Audit-instanser) som gjorts i ärendet.

js/model/case.js
Enhetstester
_tests/model/case.test.js
Objektlager
cases
Primärnyckel
id

Konstruktor

Om ett dataobjekt anges som argument populerar konstruktorn instansen med informa­tionen i det. Det används vid återskapande av ett objekt när det hämtas från objektdata­basen eller när ett sparat ärende i JSON-format läses in från fil.

Syntax

new AuditCase()
new AuditCase(data)

Parametrar

data
Dataobjekt att populera instansen med.

Fält

caseNumber
Ärendenummer.
filename
Filnamn som ärendet laddats in ifrån.
id
Identitet i databasen.
logSize
Antalet noteringar i ärendeloggen.
monitoring
Tillsynsflagga (false).
opened
Öppningsdatum.
organization
Information om den organisation (aktör) som ansvarar för den granskade digitala servicen.
service
Den digitala service som granskas i ärendet.
type
Ärendetyp ("audit").

audit()

Returnerar granskningen med angiven identitet.

Syntax

audit(id)

Parametrar

id
Granskningens identitet i databasen.

Returvärde

Den angivna granskningen, om den finns i ärendet, annars undefined.

audits()

Itererar över alla granskningar i ärendet.

Syntax

audits()

Returvärde

Ett generatorobjekt som ger en Audit-instans vid varje amrop.

Example

for (const audit of aCase.audits()) {…}

deleteAudit()

Tar bort angiven granskning ur ärendet.

Syntax

deleteAudit(audit)

Parametrar

audit
Granskning att ta bort.

Returvärde

true om granskningen fanns i ärendet och togs bort, annars false.

deleteEntry()

Tar bort angiven loggnotering ur ärendeloggen.

Syntax

deleteEntry(entry)

Parametrar

entry
Loggnotering att ta bort.

Returvärde

true om noteringen fanns i ärendeloggen och togs bort, annars false.

entry()

Returnerar loggnoteringen med angiven identitet.

Syntax

entry(id)

Parametrar

id
Loggnoteringens identitet i databasen.

Returvärde

Den angivna loggnoteringen, om den finns i ärendeloggen, annars undefined.

log()

Itererar över alla noteringar i ärendeloggen.

Syntax

log()

Returvärde

Ett generatorobjekt som ger en LogEntry-instans vid varje amrop.

Example

for (const entry of aCase.log()) {…}

open()

Öppnar ärendet. Öppningstidpunkten är sedan åtkomlig via fältet opened.

Syntax

open()
open(timestamp)

Parametrar

timestamp
Datum och klockslag att sätta som öppningstidpunkt.

Returvärde

Inget (undefined).

serialize()

Skapar ett objekt som kan ”serialiseras” och återskapas. Används när ett objekt sparas i databasen.

Granskningar och loggnoteringar ingår inte i serialiseringen, eftersom de lagras i egna objektlager och sparas separat.

Syntax

serialize()

Returvärde

Ett objekt med den information som krävs för att kunna återskapa ärendeinformationen.

setAudit()

Lägger till en granskning i ärendet.

Syntax

setAudit(audit)

Parametrar

audit
Granskning att lägga till.

Returvärde

Inget (undefined).

Undantag

TypeError
Granskningen har ingen angiven identitet (en granskning måste vara sparad i databasen innan den kan läggas till i ett ärende).

setEntry()

Lägger till en notering i ärendeloggen.

Syntax

setEntry(entry)

Parametrar

entry
Loggnotering att lägga till.

Returvärde

Inget (undefined).

Undantag

TypeError
Loggnoteringen har ingen angiven identitet (en notering måste vara sparad i databasen innan den kan läggas till i ärendeloggen).

toJSON()

Skapar ett objekt som kan ”serialiseras” och återskapas. Används när ett ärende sparas till fil.

Granskningar och loggnoteringar ingår i serialiseringen, eftersom all information som hör till ärendet behöver ingå i filen för att informationen ska gå att återskapa.

Syntax

toJSON()

Returvärde

Ett objekt med den information som krävs för att kunna återskapa ärendeinformationen.

toString()

Omvandlar ärendet till en sträng.

Syntax

toString()

Returvärde

Det formaterade ärendenumret, till exempel ”2020-1234”.
