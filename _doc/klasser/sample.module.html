sample.module.js

Modulinitiering för visning, urval och redigering av stickprov.

initModule()

Anropas av fördelaren (Dispatcher) för att instantiera vy och controller.

Funktionen använder applikationskontexten för att se vilka parametrar begäran innehåller och importerar moduler samt instantierar vy och controller baserat på det.

Om begäran innehåller någon av parametrarna ”edit” eller ”new” instantierar metoden vyklassen SampleEditView och SampleEditController.

I annat fall instantierar metoden SampleDisplayView och SampleDisplayController för att lista de krav som ska granskas för stickprovet.

Syntax

initModule(model, context)

Parametrar

model
Modellobjektet.
context
Applikationskontext.

Returvärde

Ett objekt med två fält: controller och view.
