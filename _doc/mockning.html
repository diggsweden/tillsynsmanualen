Filen _tests/mock.js innehåller ett antal funktioner för att mocka vissa ofta förekom­mande klasser och funktioner i syfte att minimera beroenden i testfall.

Funktionen mock() skapar ett ombud (Proxy) som fasad mot ett befintligt objekt eller som ersättare för ett beroende.

Funktionen mock.eventTarget() gör det möjligt att mocka HTML-element och simulera händelser, till exempel musklick eller tangenttryckningar, på dem.

Många av de övriga funktionerna mockar specifika HTML-elementtyper och används främst i tesfall för vyer. Några mockar Tillsynsmanualens egna klasser.

Mockfunktionerna importeras och exporteras av _tests/function.js, så det räcker att importera den filen i testfallen.

mock()

Skapar en ersättare för ett objekt. Funktionen skapar ett ombud (proxy) som fasad för antingen ett tomt objekt eller ett befinligt objekt där man exempelvis vill förhindra vissa metodanrop. Ombudet loggar också varje anrop till metoder i ersättningsobjektet, så att man kan verifiera dem i efterhand med expect().

Syntax

mock(dummy)
mock(obj, dummy)

Parametrar

obj
Eventuellt källobjekt att bygga en fasad framför.
dummy
Objekt vars fält och metoder ersätter sina motsvarigheter i källobjektet.

Returvärde

En Proxy-instans.

Example

const foo = mock({
    bar: "test"
}, {
    quuz: (v) => foo.bar = v
});

// använd `foo` …
expect(foo.quuz).toHaveBeenCalled.once().with("baz");
expect(foo.bar).toBe("baz");

mock.appContext()

Skapar en ersättare för applikationskontexten. Ersättaren har, som standard, advanced satt till true och history och modified satta till false. Identifierarna case, audit och sample är NaN, medan error, page, requirement, status och target är tomma strängar.

För att simulera andra parametrar, använd fältet params (se exempel nedan).

Syntax

mock.appContext()
mock.appContext(obj)

Parametrar

obj
Fält med värden som ersätter standardvärdena.

Returvärde

En Proxy-instans.

Exempel

// simulera begäran ?page=test&case=42&edit
const context = mock.appContext({
    case:   42,
    page:   "test",
    params: {
        edit: ""
    }
});

mock.confirmDialog()

Skapar en ersättare för en modal dialogruta. Funktionen specialiserar mock.eventTarget().

Fältet returnValue kan sättas till önskat värde som det returnerade löftet från metoden showModal() ska infrias med.

Syntax

mock.confirmDialog()

Returvärde

En Proxy-instans.

Exempel

const confirm = mock.confirmDialog();
confirm.returnValue = "true";
…
const result = await confirm.showModal();
// result="true"

mock.defaultQuerySelector()

Skapar en ersättare för metoden querySelector() i ett mockat DOM-dokument i ett vytestfall.

Vybasklassen ViewBase anropar document.querySelector() för att identifiera artikelelementet och statusbehållaren. Ett mockat DOM-dokument behöver därför kunna returnera dem. Om inga andra selektorer används av den testade vyklassen kan denna metod användas.

Syntax

mock.defaultQuerySelector(article, status)

Parametrar

article
Ett mockat <article>-element.
status
En mockad statusbehållare.

Returvärde

En funktion som returnerar artikelelementet för selektorn 'main > article[aria-live]' och statusbehållaren för selektorn 'main > [role="status"]'.

Exempel

const article = …;
const status  = …;

const doc = mock({
    querySelector: mock.defaultQuerySelector(article, status)
});

mock.element()

Skapar en ersättare för ett HTML-element i ett vytestfall.

Syntax

mock.element(tag)
mock.element(tag, dummy)
mock.element(tag, obj, dummy)

Parametrar

tag
Taggnamn (elementtyp).
obj
Fält som ersätter eller kompletterar standardfälten (se nedan).
dummy
Metoder som ersätter eller kompletterar standardmetoderna (se nedan).

Returvärde

En Proxy-instans.

Exempel

// Mocka <div id="foo" title="test">
const element = mock.element("div", {
    _attrs: {title: "test"},
    id:     "foo"
}, {}};

Standardfält och -metoder

Fält Värde

mock.eventTarget()

Skapar en ersättare för ett HTML-element i ett vytestfall, som det går att simulera DOM-händelser i. Funktionen specialiserar mock.element().

Metoden mockar ett element och ersätter implementationerna av addEventListener() och removeEventListener().

Den lägger också till metoden triggerEvent() för att simulera en DOM-händelse på elementet, och anropar då den lyssnare som registrerats för den angivna händelsen. Argumentet till metoden är ett objekt som ska likna Event och åtminstone innehålla fältet type.

Syntax

mock.eventTarget(tag)
mock.eventTarget(tag, dummy)
mock.eventTarget(tag, obj, dummy)

Returvärde

En Proxy-instans.

Exempel

const button = mock.eventTarget("button");
…
button.triggerEvent({type: "click"});

mock.view()

Skapar en ersättare för en vyinstans i ett controller-testfall.

Ersättaren har, som standard, advancedMode satt till true och implementerar tomma versioner av metoderna autoFocus(), hideStatus() och showSuccess(). Den imple­menterar också metoderna subscribe() och unsubscribe(). Om fältet _logErrors satts till true skriver metoden showError() felmeddelandet till konsollen. Den asynkrona metoden confirm() emulerar en modal bekräftelsedialogruta och returnerar värdet i fältet _confirm.

Ersättaren implementerar också en metod för att simulera händelseaviseringar till alla registrerade observatörer. Metoden notify() anropar observatörerna en gång per angiven händelse i nästa varv i händelseslingan. Se exempel nedan.

Syntax

mock.view(dummy)
mock.view(obj, dummy)

Parametrar

obj
Fält med värden som ersätter standardvärdena.
dummy
Metoder att implementera.

Returvärde

En Proxy-instans.

Exempel

const view = mock. view();

// Avisera två ändringshändelser.
view.notify(
    {target: "foo", type: "change", value: "foo"},
    {target: "bar", type: "change", value: "bar"}
);

// Avisera utgångshändelse separat.
view.notify({action: "save", path: "?test", type: "change"});
