Klassen Expectation representerar en förväntning som ska utvärderas i ett test. Om förväntningen inte uppfylls kastar klassen ett undantag i form av en instans av ExpectationFailure.

Det finns ett antal olika förväntningar:

  • strikt likhet (identitet)
  • likhet
  • mönstermatchning
  • instans av en specifik klass
  • antal funktionsanrop
  • parametrar i funktionsanrop.

Jämförelseförväntningarna kan negeras med fältet not. Alla metoder returnerar en referens till förväntninginstansen så att anropen kan sättas ihop till en kedja (fluent interface), till exempel: 

expect(method).toHaveBeenCalled.once().with("test");

(Funktionen expect() i _tests/functions.js skapar en Expectation-instans.)

atLeastOnce()

Verifierar att en mockmetod anropats en eller flera gånger.

Fältet toHaveBeenCalled måste ha refererats före anropet till atLeastOnce().

Syntax

atLeastOnce()

Returvärde

Den förväntningsinstans metoden anropas i.

Undantag

ExpectationFailure
Den angivna metoden anropades aldrig.
TypeError
Fältet toHaveBeenCalled refererades inte före anropet.

Exempel

expect(method).toHaveBeenCalled.atLeastOnce();

never()

Verifierar att en mockmetod inte anropats.

Fältet toHaveBeenCalled måste ha refererats före anropet till never().

Syntax

never()

Returvärde

Den förväntningsinstans metoden anropas i.

Undantag

ExpectationFailure
Den angivna metoden anropades.
TypeError
Fältet toHaveBeenCalled refererades inte före anropet.

Exempel

expect(method).toHaveBeenCalled.never();

not

Fältet not negerar efterföljande villkor.

Värde

Den förväntningsinstans fältet ingår i.

Exempel

expect(value).not.toBe(null);
expect(method).not.toHaveBeenCalled.with("test");

once()

Verifierar att en mockmetod anropats exakt en gång.

Fältet toHaveBeenCalled måste ha refererats före anropet till once().

Syntax

once()

Returvärde

Den förväntningsinstans metoden anropas i.

Undantag

ExpectationFailure
Den angivna metoden anropades aldrig, eller anropades mer än en gång.
TypeError
Fältet toHaveBeenCalled refererades inte före anropet.

Exempel

expect(method).toHaveBeenCalled.once();

times()

Verifierar att en mockmetod anropats angivet antal gånger.

Fältet toHaveBeenCalled måste ha refererats före anropet till times().

Syntax

times(count)

Parametrar

count
Förväntat antal gånger mockmetoden ska anropas.

Returvärde

Den förväntningsinstans metoden anropas i.

Undantag

ExpectationFailure
Den angivna metoden anropades fler eller färre gånger än det angivna antalet.
TypeError
Fältet toHaveBeenCalled refererades inte före anropet.

Exempel

expect(method).toHaveBeenCalled.times(2);

toBe()

Jämför strikt likhet.

toBe() motsvarar jämförelse med operatorn === och testar alltså strikt likhet (identitet). Används lämpligen för enkla datatyper som booleska eller numeriska värden och sträng­värden, samt vid test för identitet mellan två objekt. För att jämföra datum, vektorer och objekt är vanligen metoden toEqual() bättre lämpad.

Jämförelsen kan negeras med not.

Syntax

toBe(expected)

Parametrar

expected
Förväntat värde.

Returvärde

Den förväntningsinstans metoden anropas i.

Undantag

ExpectationFailure
Det faktiska utfallet är inte strikt lika med det angivna förväntade värdet.

Exempel

expect(value).toBe(42);

toBeAnInstanceOf()

Jämför objektklass.

Används för att verifiera att ett objekt är en instans av förväntad klass.

Jämförelsen kan negeras med not.

Syntax

toBeAnInstanceOf(class)

Parametrar

class
Förväntad klass.

Returvärde

Den förväntningsinstans metoden anropas i.

Undantag

ExpectationFailure
Utfallet är inte ett objekt av den angivna klassen.

Exempel

expect(obj).toBeAnInstanceOf(MyClass);

toEqual()

Jämför icke-strikt likhet.

toEqual() motsvarar jämförelse med operatorn == för skalärer och testar alltså typ­oberoende likhet. Används lämpligen för att jämföra vektorer, datum eller objekt.

  • Vektorer: jämför längderna och matchar varje element icke-strikt.
  • Datum: Om parametern är ett datum ska utfallet vara ett datum med samma värde; om utfallet är ett datum omvandlas parametern till ett datum och jämförs.
  • DOM-noder: jämför nodklass, underordnade noder och attribut.
  • null: utfallet ska vara null.
  • Objekt: jämför fält för fält (icke-strikt); jämför avsiktligt inte klass.
  • Reguljärt uttryck: utför mönstermatchning mot utfallet.
  • Sträng: om både parameter och utfall är strängar, men inte lika, visar felmeddelandet vid vilken position de skiljer sig.
  • Skalär: typoberoende jämförelse.

Jämförelsen kan negeras med not.

Syntax

toEqual(expected)

Parametrar

expected
Förväntat värde.

Returvärde

Den förväntningsinstans metoden anropas i.

Undantag

ExpectationFailure
Det faktiska utfallet är inte lika med det angivna förväntade värdet.

Exempel

expect(value).toEqual(["foo", "bar"]);

toHaveBeenCalled

Förebereder förväntningsinstansen på matchningsmetoder för funktionsanrop. Fältet måste refereras innan metoden with() eller någon av metoderna för verifiering av antalet anrop kan användas.

Värde

Den förväntningsinstans fältet ingår i.

Exempel

expect(method).toHaveBeenCalled.once();

toMatch()

Mönstermatchning mot ett regulärt uttryck.

Jämförelsen kan negeras med not.

Syntax

toMatch(expr)

Parametrar

expr
Reguljärt uttryck att matcha mot utfallet.

Returvärde

Den förväntningsinstans metoden anropas i.

Undantag

ExpectationFailure
Utfallet matchar inte det reguljära uttrycket.

Exempel

expect(value).toMatch(/^\d+$/);

with()

Verifiera argument vid anrop till mockfunktioner. Om funktionen anropats en gång jämförs parameteruppsättningen med det anropet. Om funktionen anropats flera gånger ska varje parameter till with() vara en vektor med parametrarna till respektive anrop.

Parametrarna jämförs icke-strikt. En förväntad parameter som är en funktion kan matchas med anyFunction().

Fältet toHaveBeenCalled måste ha refererats före anropet till with().

Syntax

with(arg1, …, argN)

Parametrar

argN
Förväntade anropsparametrar.

Returvärde

Den förväntningsinstans metoden anropas i.

Undantag

ExpectationFailure
Antalet parametrar skiljer, eller någon parameter i utfallet är inte icke-strikt lika med den förväntade parametern.

Exempel

expect(method).toHaveBeenCalled.once().with("test", 42);

expect(method).toHaveBeenCalled.times(2).with(
    ["foo", 13],
    ["bar", 42]
);

anyFunction()

Matchar en funktion som parameter i ett funktionsanrop.

Syntax

expect.anyFunction()

Returvärde

En tom funktion.

Exempel

expect(method).toHaveBeenCalled.with(42, expect.anyFunction());

exception()

Skapar en förväntning om ett synkront undantag. Det anrop som förväntas generera ett undantag måste ske i en funktion som exception() anropar, annars skulle felet förhindra anropet.

För förväntade asynkrona undantag, se expect.failure().

Syntax

expect.exception(func)

Parametrar

func
Synkron funktion som förväntas generera ett undantag.

Returvärde

En Expectation-instans.

Exempel

expect.exception(() => divideBy(0));

failure()

Skapar en förväntning om ett asynkront undantag. Det anrop som förväntas generera ett undantag måste ske i en funktion som failure() anropar, annars skulle felet förhindra anropet.

För förväntade synkrona undantag, se expect.exception().

Syntax

expect.failure(func)

Parametrar

func
Asynkron funktion som förväntas generera ett undantag.

Returvärde

En Expectation-instans.

Exempel

await expect.failure(() => load("nosuchfile.json"));
